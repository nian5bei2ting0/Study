# fine-plugin-dev

帆软 FineReport 11 本地插件开发 Cursor Skill。基于 `E:\AI\cursor\fine_plugins\` 下多个实战插件归纳。

## 安装

**个人技能（推荐，跨项目可用）：**

将本目录复制或同步到：

```
%USERPROFILE%\.cursor\skills\fine-plugin-dev\
```

需包含：`SKILL.md`、`templates.md`、`reference.md`、`troubleshooting.md`。

**项目技能：** 复制到具体插件仓库的 `.cursor/skills/fine-plugin-dev/`。

## 使用

在对话中提及「帆软插件」「FineReport 插件」「plugin.xml」「决策三件套」等时，Agent 应自动匹配本 skill；也可显式说：按 `fine-plugin-dev` skill 开发。
