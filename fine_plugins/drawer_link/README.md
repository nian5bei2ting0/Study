# 抽屉报表与指标提示超链接插件

## 功能

安装后，在设计器「超级链接 > 添加链接」中新增：

### 抽屉报表
- 选择网络报表（cpt/frm 等）
- 抽屉方向：上 / 下 / 左 / 右
- 参数列表；传参方式 GET / POST
- 左/右 → 宽度(px)；上/下 → 高度(px)

### 指标提示
- 提示内容
- 字体、字体大小、字体颜色
- 提示框背景色

预览时点击超链接：抽屉报表以抽屉滑出展示；指标提示在点击位置弹出样式提示框。

## 构建

```bash
mvn -q clean package
```

产物：`target/plugin-com.fr.plugin.drawer.link-1.0.3.zip`

## 安装

设计器或决策平台「插件管理 > 从本地安装」，选择 zip 后重启设计器。
