## 学习方法（很重要）

1. **先看**：通读当日 .md，理解概念。
2. **再敲**：把 code/ 下当日示例代码逐行敲进编辑器并运行。
3. **改一改**：故意改几个值，观察输出变化，理解为什么。
4. **做练习**：完成 .md 末尾的"每日练习"。
5. **对答案**：练习答案在 .md 末尾"参考答案"折叠区。

> 卡住超过 20 分钟就看答案，看懂后**关掉答案重新默写**，不要照抄。
