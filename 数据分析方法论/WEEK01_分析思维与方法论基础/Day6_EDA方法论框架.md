# Day6 · EDA 方法论框架

> EDA（探索性数据分析）不是"画一堆图"，是"用图回答问题"。

---

## 一、方法论框架

### 1. EDA 的核心目标

| 目标 | 回答的问题 | 产出 |
|------|-----------|------|
| 理解分布 | 变量长什么样 | 分布图、统计量 |
| 发现异常 | 有没有不对的 | 异常清单、处理建议 |
| 发现关系 | 变量间什么关系 | 相关矩阵、分组对比 |
| 生成假设 | 可能有什么模式 | 假设清单、待验证项 |
| 评估可用性 | 能不能支撑分析 | 数据质量结论 |

### 2. 单变量分析

**数值变量**：
- 集中趋势：均值、中位数、众数
- 离散程度：标准差、IQR、极差
- 分布形态：偏度（正偏长尾右）、峰度（尖峰/平峰）
- 分位数：P5/P25/P50/P75/P95（比均值更抗异常）

**判断分布形态**：
- 偏度 > 1：严重正偏（长尾在右），常见于金额、收入
- 偏度 < -1：严重负偏
- 峰度 > 3：尖峰（异常值多）
- 峰度 < 3：平峰

**处理建议**：
- 正偏严重 → 对数变换
- 双峰 → 可能是混合群体，需分层

**分类变量**：
- 频次分布：每类多少
- 占比：相对大小
- 基尼系数 / 香农熵：衡量集中度

### 3. 双变量分析

| 变量组合 | 分析方法 | 关键问题 |
|---------|---------|---------|
| 数值 × 数值 | 散点图、相关系数 | 线性关系？非线性？ |
| 数值 × 分类 | 箱线图、分组统计 | 组间有差异？ |
| 分类 × 分类 | 交叉表、堆叠条 | 是否独立？ |

**相关 ≠ 因果**：
- 相关 0.9 不代表 A 导致 B
- 可能是 C 同时影响 A 和 B（混淆变量）
- 可能是时间先后（A 在 B 之前不代表 A 导致 B）

### 4. 多变量分析

- **相关性矩阵**：发现高度相关的特征（多重共线性）
- **降维可视化**：PCA / t-SNE / UMAP 看群体结构
- **聚类预探**：KMeans 看有没有自然群体
- **分组对比**：按关键维度分组，看目标变量差异

### 5. 异常值诊断

| 场景 | 方法 |
|------|------|
| 单变量 | 3σ / IQR / 业务规则 |
| 多变量 | 孤立森林 / LOF / DBSCAN |
| 时序 | 移动平均残差 / STL 分解残差 |

**异常值处理决策树**：
```
是异常吗？
├── 是错误吗？
│   ├── 是 → 修正或删除
│   └── 否 → 是真实极端值吗？
│       ├── 是 → 保留，考虑分箱或对数变换
│       └── 否 → 需进一步调查
```

### 6. EDA 报告结构

```
1. 数据概览
2. 质量评估（六维度）
3. 单变量分析（关键变量分布）
4. 双变量分析（关键关系）
5. 多变量分析（群体结构）
6. 异常值清单
7. 假设清单（待验证）
8. 可用性结论
```

## 二、案例复盘：某金融交易 EDA 全流程

### 1. 数据概览
- 交易表：100 万行，12 字段，近 6 个月
- 目标：发现可疑交易模式

### 2. 单变量分析

**交易金额**：
- 均值 5000，中位数 800
- 偏度 8.5（严重正偏，长尾）
- P95 = 12000，P99 = 80000
- **结论**：金额严重长尾，需对数变换

**交易时间**：
- 24 小时分布：白天多，深夜少
- 但深夜交易占比 8%（异常偏高）
- **假设**：深夜交易可能与欺诈相关

### 3. 双变量分析

**金额 × 是否欺诈**：
- 欺诈交易平均金额 15000 vs 正常 4500
- 欺诈交易 P95 = 50000
- **结论**：欺诈交易金额显著更高

**时间 × 是否欺诈**：
- 深夜欺诈率 15% vs 白天 2%
- **结论**：深夜是高风险时段

### 4. 多变量分析

**PCA 降维**：
- 2D 可视化发现欺诈交易形成独立群体
- **假设**：欺诈交易有可区分的特征组合

**金额 × 频率 × 欺诈**：
- 高频小额 + 低频大额 = 两种欺诈模式
- **假设**：套现（高频小额）+ 转移（低频大额）

### 5. 异常值清单

| 异常类型 | 数量 | 业务确认 |
|---------|------|---------|
| 金额 > 100 万 | 50 条 | 30 真实大客户，20 待查 |
| 单日交易 > 100 次 | 200 条 | 80 套现，120 正常高频 |
| 深夜交易 | 8000 条 | 需结合金额判断 |

### 6. 假设清单（待建模验证）

1. 深夜交易欺诈率更高
2. 欺诈交易金额更高
3. 高频小额是套现模式
4. 欺诈交易有可聚类的特征组合

### 7. 可用性结论
- 数据可支撑建模
- 关键特征：金额、时间、频率、设备
- 需构造衍生特征：深夜占比、频率突变、金额分散度

## 三、思考练习

1. 选一个数值变量，计算均值/中位数/偏度/峰度，判断是否需要变换。
2. 选两个变量做双变量分析，写出"相关但不一定因果"的理由。
3. 列出你 EDA 后的 3 个假设，并设计验证方法。

## 四、今日小结

- EDA 是用图回答问题，不是画一堆图
- 单变量看分布，双变量看关系，多变量看结构
- 相关 ≠ 因果，要找混淆变量
- 异常值要区分"错误"和"真实极端"
- EDA 产出假设清单，为建模铺路
