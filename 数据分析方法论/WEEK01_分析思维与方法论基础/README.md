# WEEK01 · 分析思维与方法论基础

> **本周目标**：建立"先想清楚再动手"的分析思维，掌握从业务问题到数据动作的完整映射。
> **核心问题**：拿到一个业务问题，如何把它变成一个可分析、可度量、可行动的数据任务？

---

## 本周路线

| Day | 主题 | 方法论核心 | 案例复盘 |
|-----|------|-----------|---------|
| 1 | 数据分析的本质与角色认知 | 分析四层次 / 角色演进 / 价值定位 | 某互联网公司分析团队职能演进 |
| 2 | 业务问题定义与拆解 | MECE / 假设树 / 问题-数据映射 | 某电商"GMV 下滑"诊断 |
| 3 | 指标体系设计 | 北极星 / OSM / AARRR / 指标字典 | 某内容平台用户增长体系 |
| 4 | 分析框架与思维模型 | 5W2H / 杜邦 / RFM / PEST | 某零售连锁杜邦分析拆解 |
| 5 | 数据理解与质量评估 | EDA 六步法 / 数据质量六维度 | 某银行风控数据盘点 |
| 6 | EDA 方法论框架 | 单变量 / 双变量 / 多变量 / 异常 | 某金融交易 EDA 全流程 |
| 7 | 综合复盘与分析报告撰写 | 报告结构 / 结论先行 / 图表选择 | 一份完整分析报告的诞生 |

---

## 学完本周你能做到

- [ ] 说清数据分析的四个层次和自己的角色定位
- [ ] 用 MECE + 假设树把模糊业务问题拆成可验证子问题
- [ ] 为一个业务场景设计三层指标体系并写指标字典
- [ ] 至少熟练运用 3 种分析框架（5W2H / 杜邦 / RFM）
- [ ] 用六维度评分卡评估数据是否可建模
- [ ] 按 EDA 六步法完成一次完整探索性分析
- [ ] 按金字塔结构撰写一份分析报告
