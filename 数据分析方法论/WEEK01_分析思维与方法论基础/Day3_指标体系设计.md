# Day3 · 指标体系设计

> 指标是分析的"语言"。指标选错，整个团队方向就错。

---

## 一、方法论框架

### 1. 北极星指标（North Star Metric）

**定义**：一个能反映产品为用户创造核心价值的单一核心指标。

**选择标准**：
- 反映核心价值（不是虚荣指标）
- 可度量、可拆解
- 团队都能理解并为之努力
- 与商业结果正相关

**案例**：
- 电商：GMV / 下单用户数
- 内容平台：日均互动用户数（而非 DAU）
- SaaS：年度经常性收入（ARR）
- 工具产品：周活跃使用天数

**反例**：DAU 常常是虚荣指标——用户来了但没产生价值。

### 2. OSM 框架

**OSM = Objective（目标）→ Strategy（策略）→ Measurement（度量）**

```
O：提升用户留存
├── S1：提升内容质量
│   ├── M1.1：完播率
│   └── M1.2：优质内容占比
├── S2：提升个性化推荐
│   ├── M2.1：推荐点击率
│   └── M2.2：推荐内容消费时长
└── S3：降低流失触发点
    ├── M3.1：关键页面跳出率
    └── M3.2：负反馈次数
```

**要点**：每个策略都要落到可度量的 M，否则策略就是口号。

### 3. AARRR 海盗指标

| 阶段 | 指标 | 关注点 |
|------|------|--------|
| Acquisition 获客 | 新增用户数、获客成本 | 流量从哪来 |
| Activation 激活 | 激活率、首次价值时刻 | 用户是否体验到价值 |
| Retention 留存 | 次日/7日/30日留存率 | 用户是否回来 |
| Revenue 收入 | ARPU、付费率、LTV | 用户是否付费 |
| Referral 推荐 | 分享率、K 因子 | 用户是否带来新用户 |

**RARRA 变体**（留存优先）：Retention → Activation → Referral → Revenue → Acquisition。适用于流量红利结束后的存量时代。

### 4. 指标分层

```
L0 核心指标（1-3 个）：北极星 + 一级拆解
   └── L1 一级拆解（5-10 个）：按维度/漏斗拆
       └── L2 二级拆解（10-30 个）：细分到可行动
           └── 过程指标（30+）：日常监控
```

**原则**：越上层越稳定（不轻易改），越下层越灵活（按需调整）。

### 5. 指标字典要素

每个指标必须记录：

| 要素 | 说明 | 示例 |
|------|------|------|
| 指标名 | 规范命名 | 次日留存率 |
| 定义 | 一句话讲清 | 注册次日仍活跃的用户占比 |
| 口径 | 精确计算公式 | 次日活跃用户数 / 当日新增用户数 |
| 维度 | 可拆解的切面 | 渠道、平台、地域 |
| 更新频率 | 多久算一次 | 每日 |
| 负责人 | 谁对口径负责 | 用户增长组-张三 |
| 异常阈值 | 什么算异常 | 环比降幅 > 5% 告警 |
| 依赖数据源 | 数据从哪来 | 用户行为日志表 |

### 6. 代理指标与虚荣指标

- **代理指标**：核心指标不可直接观测时，用相关指标代替。例：用户满意度 → NPS 评分
- **虚荣指标**：只涨不跌、不驱动行动的指标。例：累计注册用户数（只增不减，无法行动）

**判断**：如果这个指标变了，你会做什么不同的事？如果答案是"不知道"，就是虚荣指标。

### 7. 常见陷阱

- **指标冲突**：提升点击率 vs 提升满意度（可能矛盾）
- **口径不一致**：不同部门对"活跃"定义不同
- **指标过载**：看板 50 个指标，没人能抓住重点
- **指标僵化**：北极星永远不变，跟不上业务阶段

## 二、案例复盘：某内容平台用户增长体系

### 1. 业务背景
- 短视频内容平台，DAU 500 万，但增长停滞
- 原北极星：DAU
- 问题：DAU 在涨，但人均时长在降，广告收入不增反降

### 2. 北极星重新选择

| 候选指标 | 优点 | 缺点 | 评估 |
|---------|------|------|------|
| DAU | 简单 | 可被刷量虚高 | ❌ |
| 人均时长 | 反映消费 | 鼓励长内容，损害完播 | ❌ |
| 日均互动用户数 | 反映价值交付 | 较难刷量 | ✅ |
| 完播率 | 反映内容质量 | 单一维度 | 备选 |

**最终选择**：日均互动用户数（点赞/评论/分享/收藏任一即算互动）

**理由**：互动是用户对内容价值的"投票"，比"看了多久"更真实。

### 3. OSM 拆解

```
O：提升日均互动用户数
├── S1：提升内容质量
│   ├── M1.1：完播率（目标 60%）
│   └── M1.2：优质内容占比（目标 30%）
├── S2：提升推荐精准度
│   ├── M2.1：推荐点击率（目标 25%）
│   └── M2.2：互动率（目标 8%）
└── S3：降低互动门槛
    ├── M3.1：互动按钮曝光率
    └── M3.2：首次互动转化率
```

### 4. 指标字典示例

**指标名**：日均互动用户数
- **定义**：当日产生至少一次互动（赞/评/转/藏）的去重用户数
- **口径**：count(distinct user_id) where action in ('like','comment','share','favorite') and dt = today
- **维度**：渠道、平台、地域、内容品类
- **更新频率**：每日凌晨
- **负责人**：用户增长组-李四
- **异常阈值**：环比降幅 > 8% 告警
- **依赖数据源**：用户互动行为表

### 5. 教训
- 选错北极星（DAU）导致团队刷量，损害真实价值
- 指标选择要问"这个指标涨了，业务真的变好了吗？"
- 北极星不是永恒的，要随业务阶段调整

## 三、思考练习

1. 你所在业务中，哪个"指标"其实是虚荣指标？为什么？
2. 为你的业务选一个北极星指标，并用 OSM 拆成 3 层。
3. 为拆解出的一个核心指标，写完整的指标字典。

---

## 四、今日小结

- 北极星指标反映核心价值，不是虚荣指标
- OSM 把目标落到可度量的 M
- AARRR 是用户生命周期的通用框架
- 指标字典让口径可追溯、可复用
