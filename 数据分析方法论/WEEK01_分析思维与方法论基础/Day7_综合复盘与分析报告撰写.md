# Day7 · 综合复盘与分析报告撰写

> 分析的终点不是图表，是让决策者看懂并行动。

---

## 一、方法论框架

### 1. 金字塔原理

**核心思想**：结论先行，论据支撑，数据佐证。

```
        [核心结论]
       /     |     \
   [论据1] [论据2] [论据3]
    / \      / \      / \
  [数据][数据][数据][数据][数据][数据]
```

**反面**：先铺数据 → 再说论据 → 最后给结论（让读者自己拼图）。

**为什么结论先行**：
- 决策者时间有限，3 秒抓不住就放弃了
- 结论先行让读者带着结论看论据，更容易理解
- 先结论后论据 = 演绎；先数据后结论 = 归纳（更累）

### 2. 报告结构模板

```
1. 一句话结论（3 秒能读完）
2. 背景与问题（为什么分析这个）
3. 核心发现（3-5 个，每个一句话）
4. 详细分析（每个发现的论据 + 数据）
5. 行动建议（谁做什么，预期效果）
6. 附录（数据明细、方法说明）
```

### 3. 图表选择决策表

| 目的 | 推荐图表 | 不推荐 |
|------|---------|--------|
| 比较大小 | 柱状图 | 饼图（多于 5 类） |
| 占比构成 | 饼图（≤5 类）/ 堆叠条 | 3D 饼图 |
| 趋势变化 | 折线图 | 柱状图（趋势） |
| 分布形态 | 直方图 / 箱线图 | 折线图 |
| 相关关系 | 散点图 | 柱状图 |
| 排名 | 条形图（横向） | 饼图 |
| 多维对比 | 雷达图 / 热力图 | 多柱堆叠 |

**通用原则**：
- 一图一结论（图标题就是结论）
- 能用简单图不用复杂图
- 颜色 ≤ 5 种
- 标注关键数值

### 4. 一页纸报告 vs 详细报告

| 类型 | 场景 | 结构 |
|------|------|------|
| 一页纸 | 高管快速决策 | 结论 + 3 个发现 + 1 个建议 |
| 详细报告 | 团队复盘 / 存档 | 完整 6 段结构 |
| 仪表盘 | 持续监控 | 指标 + 异常高亮 |

### 5. 报告的"三秒原则"

读者 3 秒内应该能抓住：
1. 核心结论是什么
2. 我需要做什么
3. 不做会怎样

**自检**：把报告给一个不懂业务的人看 3 秒，问他记住了什么。

### 6. 常见反模式

- **数据堆砌**：50 张图，没有结论
- **图表炫技**：3D / 动态 / 复杂配色，掩盖信息
- **结论模糊**："有一定影响"、"可能相关"——等于没说
- **建议空泛**："加强运营"、"提升体验"——无法执行
- **没有边界**：不说分析范围、数据时间、置信度

## 二、案例复盘：一份完整分析报告的诞生

### 1. 需求
业务方："上个月用户活跃度下降，帮我们看看。"

### 2. 问题澄清
- 活跃度定义？→ DAU
- 下降幅度？→ 环比 -12%
- 时间窗口？→ 上月
- 行动意图？→ 决定是否做召回活动

### 3. 分析过程（用本周方法）
- Day2 假设树：DAU = 新增 + 老用户回访 + 留存衰减
- Day3 指标拆解：DAU → 新增 DAU + 留存 DAU + 召回 DAU
- Day5 数据质量：确认数据无缺失
- Day6 EDA：发现新增正常，留存 DAU 下降

### 4. 报告撰写

**【一句话结论】**
上月 DAU 环比下降 12%，主因是 30 日留存率从 40% 降到 28%，建议优先优化新用户首周体验而非做召回活动。

**【背景】**
上月 DAU 从 100 万降到 88 万，业务方担心影响收入，考虑做召回活动。

**【核心发现】**
1. 新增用户正常（环比 +3%），不是获客问题
2. 30 日留存率从 40% 降到 28%，是 DAU 下降主因
3. 留存下降集中在"注册后 3-7 天"流失
4. 该时段对应新版引导流程上线，疑似体验问题

**【详细分析】**
- 新增 DAU：35 万 → 36 万（+3%）
- 留存 DAU：65 万 → 52 万（-20%）
- 留存拆解：次日留存 60%→58%（正常波动），7 日留存 45%→30%（异常）
- 新版引导流程上线时间与留存下降时间吻合

**【行动建议】**
1. **优先级 1**：复盘新版引导流程，A/B 测试对比旧版
2. **优先级 2**：针对 3-7 天流失用户做精准触达（非全量召回）
3. **暂缓**：全量召回活动（治标不治本，留存问题不解决召回也留不住）

**【附录】**
- 数据时间：上月 1-30 日 vs 前 1-30 日
- 数据来源：用户行为日志
- 置信度：留存下降样本量 50 万，p < 0.01

### 5. 教训
- 如果直接做召回活动，会花预算但治标不治本
- 报告的核心价值是"否定了业务方的第一直觉"，引导到真因
- 好报告 = 结论 + 证据 + 可执行建议 + 边界说明
