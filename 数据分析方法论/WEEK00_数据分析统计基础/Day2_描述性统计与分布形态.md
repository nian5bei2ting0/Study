# Day2 · 描述性统计与分布形态

> 描述性统计是用几个数字概括一整堆数据。但要会用，先要懂每个数字的"脾气"。

---

## 一、原理：统计量是分布的摘要

### 1. 两类统计量

| 类型 | 回答 | 例子 |
|------|------|------|
| 集中趋势 | 数据"中心"在哪 | 均值、中位数、众数 |
| 离散程度 | 数据"散"多开 | 方差、标准差、IQR、极差 |

**关键认知**：不同统计量有不同"脾气"，用错场合会误导。

### 2. 集中趋势对比

| 统计量 | 优点 | 缺点 | 适用 |
|--------|------|------|------|
| 均值 | 用到所有数据、可数学运算 | 受极端值影响大 | 对称分布 |
| 中位数 | 抗极端值 | 只用中间值 | 长尾分布 |
| 众数 | 适用于分类 | 可能不唯一 | 分类数据 |

**经典案例**：
- 10 个人，9 个收入 5 万，1 个收入 500 万
- 均值 = 55 万（被拉高）
- 中位数 = 5 万（更真实）
- → 长尾数据用中位数

### 3. 离散程度对比

| 统计量 | 含义 | 优点 | 缺点 |
|--------|------|------|------|
| 极差 | max - min | 简单 | 只用两端，受异常影响 |
| 方差/标准差 | 平均偏离均值的程度 | 用到所有数据 | 受异常影响、假设对称 |
| IQR | Q3 - Q1（中间50%的范围） | 抗极端值 | 只用中间 |

**直觉**：
- 标准差大 = 数据散得开
- IQR 比 标准差 更抗异常

### 4. 分位数

| 分位数 | 含义 |
|--------|------|
| P50 = 中位数 | 一半数据在这之下 |
| P25 = Q1 | 25% 数据在这之下 |
| P75 = Q3 | 75% 数据在这之下 |
| IQR = Q3 - Q1 | 中间 50% 的范围 |

**为什么用分位数**：
- 抗极端值
- 直观（"前 10%" 比 "1.28σ" 好懂）
- 不假设分布

### 5. 分布形态：偏度与峰度

**偏度（Skewness）**：衡量不对称程度
- 0：对称
- > 0：正偏（长尾在右，小值多）
- < 0：负偏（长尾在左，大值多）

**峰度（Kurtosis）**：衡量尾部厚度
- 3：正态分布的峰度
- > 3：尖峰厚尾（极端值多）
- < 3：平峰薄尾

**判断**：
| 偏度 | 形态 | 处理 |
|------|------|------|
| ≈ 0 | 对称 | 可用均值/标准差 |
| > 1 | 严重正偏 | 用中位数/IQR，或对数变换 |
| < -1 | 严重负偏 | 同上 |

### 6. 箱线图原理

```
      ┌──────┐
   ───┤      ├───
      └──────┘
   Q1  Q2  Q3
   |IQR|
```

- 箱体：Q1 到 Q3（中间 50%）
- 箱中线：中位数
- 须：1.5×IQR 范围内
- 须外的点：异常值

**为什么是 1.5 倍 IQR**：经验值，约等于正态分布的 ±2.7σ，覆盖 99.3%。

## 二、方法：怎么用

### 1. 描述一份数据的标准动作

```
1. 看分布形状（直方图）
   - 对称？长尾？双峰？
2. 算集中趋势
   - 对称用均值，长尾用中位数
3. 算离散程度
   - 对称用标准差，长尾用 IQR
4. 算分位数
   - P5/P25/P50/P75/P95
5. 画箱线图
   - 看异常值
6. 判断偏度峰度
   - 决定要不要变换
```

### 2. 选择统计量的决策表

| 数据形态 | 集中趋势 | 离散程度 | 异常检测 |
|---------|---------|---------|---------|
| 对称（正态） | 均值 | 标准差 | 3σ / z-score |
| 长尾（正偏） | 中位数 | IQR | 1.5×IQR |
| 双峰 | 分层后分别描述 | - | - |
| 分类 | 众数 | - | - |

### 3. 数据变换

| 变换 | 适用 | 效果 |
|------|------|------|
| 对数变换 | 正偏长尾 | 压缩右尾，趋近正态 |
| 标准化（z-score） | 量纲不同 | 统一尺度 |
| 分箱 | 连续转离散 | 简化分析 |
| Box-Cox | 不确定 | 自动选变换 |

**注意**：对数变换要求所有值 > 0，0 值用 log(x+1)。

### 4. 常见误区

- 长尾数据用均值描述"典型值" → 被极端值拉偏
- 用标准差做异常检测但数据不正态 → 误判
- 只看均值不看分布 → 漏掉双峰/长尾
- 把"平均用户"当真实用户 → 不存在的人

## 三、代码示例要点

```python
import numpy as np
import pandas as pd
from scipy import stats

# 金额数据（长尾）
amounts = np.random.lognormal(3, 1, 10000)

print("均值:", amounts.mean())      # 被拉高
print("中位数:", np.median(amounts)) # 更真实
print("标准差:", amounts.std())
print("IQR:", np.percentile(amounts, 75) - np.percentile(amounts, 25))
print("偏度:", stats.skew(amounts))   # >0 正偏
print("峰度:", stats.kurtosis(amounts)) # >0 厚尾

# 分位数
print("P5/P25/P50/P75/P95:", np.percentile(amounts, [5,25,50,75,95]))

# 对数变换后
log_amounts = np.log(amounts)
print("变换后偏度:", stats.skew(log_amounts))  # 趋近0
```

## 五、今日小结

- 集中趋势：均值（对称）、中位数（长尾）、众数（分类）
- 离散程度：标准差（对称）、IQR（长尾）
- 偏度 > 1 → 正偏长尾 → 用中位数 + 对数变换
- 箱线图用 1.5×IQR 判异常
- 描述数据先看形状，再选统计量
