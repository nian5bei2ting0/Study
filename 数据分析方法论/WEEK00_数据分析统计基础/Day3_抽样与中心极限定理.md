# Day3 · 抽样与中心极限定理

> 这是统计学最重要的定理。没有它，所有"用样本推断总体"的方法都不成立。

---

## 一、原理：为什么样本能推断总体

### 1. 总体 vs 样本

| 概念 | 含义 | 例子 |
|------|------|------|
| 总体 | 研究对象的全体 | 全部用户 |
| 样本 | 从总体中抽的一部分 | 1000 个用户 |
| 参数 | 总体的真实值（通常未知） | 全体用户平均年龄 μ |
| 统计量 | 样本算出来的值 | 1000 人的平均年龄 x̄ |

**核心问题**：我们通常只能看到样本，怎么知道总体？

### 2. 抽样方法

| 方法 | 说明 | 适用 | 风险 |
|------|------|------|------|
| 简单随机 | 每个个体等概率被抽 | 通用 | 可能不均衡 |
| 分层抽样 | 按子群体分层再抽 | 子群差异大 | 复杂 |
| 整群抽样 | 抽整个群 | 群内相似 | 群间差异大时偏差 |
| 方便抽样 | 谁方便抽谁 | 不可取 | 严重偏差 |

**关键认知**：抽样偏差比样本量更致命。100 万有偏样本 < 1000 个随机样本。

**经典案例**：1936 年《文学文摘》用 240 万电话用户预测大选，全错——因为当年有电话的是富人，抽样有偏。

### 3. 中心极限定理（CLT）

**大白话**：不管总体是什么分布，只要样本量足够大（通常 n ≥ 30），**样本均值的分布**近似正态。

**为什么重要**：
- 总体可能是任何形状（长尾、双峰）
- 但样本均值是正态的
- 正态分布有现成工具（z 检验、t 检验）
- → 我们能用样本均值做推断

**直觉**：
```
总体（任意分布）→ 抽很多样本 → 每个样本算均值 → 这些均值近似正态
```

### 4. 标准误（Standard Error）

**定义**：样本均值的标准差，衡量"样本均值有多不确定"。

**公式**：SE = σ / √n
- σ：总体标准差
- n：样本量

**直觉**：
- 样本越大 → SE 越小 → 估计越准
- 总体越散（σ 大）→ SE 越大 → 估计越不准

**与标准差的区别**：
| 概念 | 描述 | 公式 |
|------|------|------|
| 标准差 | 数据点的散布 | σ |
| 标准误 | 样本均值的散布 | σ/√n |

### 5. 大数定律

**大白话**：样本量越大，样本均值越接近总体均值。

**与 CLT 的区别**：
- 大数定律：n → ∞ 时，x̄ → μ（收敛到真值）
- CLT：n 足够大时，x̄ 的分布近似正态（分布形状）

### 6. 置信区间（预告，Day4 详解）

**直觉**：用样本算一个范围，真值大概率在这个范围内。

**公式**：x̄ ± z × SE
- x̄：样本均值
- z：置信水平对应的 z 值（95% 置信 → z=1.96）
- SE：标准误

**例**：1000 人平均年龄 35 岁，SE=0.5，95% 置信区间 = 35 ± 0.98 = [34.02, 35.98]。

## 二、方法：怎么用

### 1. 抽样实践

| 场景 | 方法 |
|------|------|
| A/B 测试分流 | 简单随机（hash） |
| 用户调研 | 分层抽样（按群体） |
| 数据探索 | 随机抽样（大数据集先抽样看） |
| 异常检测 | 全量（不抽样） |

### 2. 样本量怎么定

**影响样本量的因素**：
- 总体方差 σ²（越大需要越多）
- 允许误差 E（越小需要越多）
- 置信水平（越高需要越多）

**公式**：n = (z × σ / E)²

**例**：σ=10，允许误差 E=1，95% 置信 → n = (1.96×10/1)² ≈ 384

### 3. 何时样本量不够

| 场景 | 最小样本量 |
|------|-----------|
| 描述统计 | 30 |
| 假设检验 | 每组 30 |
| 细分子群分析 | 每子群 30+ |
| 罕见事件（如欺诈） | 正样本 100+ |

### 4. 抽样偏差的识别

**自检**：
- 样本是否随机抽取？
- 是否有自选择偏差？（只有活跃用户填问卷）
- 是否有覆盖偏差？（只触达了部分人群）
- 是否有存活偏差？（只看了留下的用户）

### 5. 常见误区

- **样本越大越好**：有偏样本再大也没用
- **样本代表总体**：要检查抽样方法
- **小样本下结论**：n < 30 时 CLT 不一定成立
- **忽略存活偏差**：只看现有用户，漏掉流失用户

## 三、代码示例要点

```python
import numpy as np

# 演示 CLT：总体是长尾分布
population = np.random.lognormal(3, 1, 1000000)

# 抽 1000 个样本，每个样本 50 个，算均值
sample_means = [np.random.choice(population, 50).mean() for _ in range(1000)]

# 看样本均值的分布
import matplotlib.pyplot as plt
plt.hist(sample_means, bins=50)
# 即使总体长尾，样本均值近似正态！

# 标准误
se = population.std() / np.sqrt(50)
print("理论SE:", se, " 实际样本均值std:", np.std(sample_means))

# 置信区间
sample = np.random.choice(population, 1000)
mean = sample.mean()
se = sample.std() / np.sqrt(1000)
ci = (mean - 1.96*se, mean + 1.96*se)
print(f"95%置信区间: {ci}, 真值: {population.mean()}")
```

## 五、今日小结

- 样本能推断总体，前提是抽样无偏
- CLT：样本量足够大时，样本均值近似正态
- 标准误 SE = σ/√n，衡量估计的不确定性
- 样本量公式：n = (z×σ/E)²
- 抽样偏差比样本量更致命
