# Day4 · 假设检验

> 假设检验是统计学的"裁判"：判断差异是真实的还是巧合。

---

## 一、原理：假设检验的逻辑

### 1. 核心思想（反证法）

```
1. 假设"没差异"（H0）
2. 在 H0 下，观察到当前差异的概率多大？
3. 概率很小（p < 0.05）→ 拒绝 H0 → 有差异
4. 概率不小 → 不拒绝 H0 → 不足以说有差异
```

**大白话**："假设没区别，那看到这么大差异的可能性很小，所以应该有区别。"

### 2. 两类错误

| 错误 | 含义 | 代价 |
|------|------|------|
| 第一类（α，弃真） | 没差异说有差异 | 误报（如：无效功能上线） |
| 第二类（β，取伪） | 有差异说没差异 | 漏报（如：有效功能没上线） |

**显著性水平 α**：容忍的第一类错误概率，通常 0.05。

**检验功效 1-β**：正确发现差异的概率，通常希望 ≥ 0.8。

**权衡**：α 越严（如 0.01），β 越大（漏报多）。鱼与熊掌不可兼得。

### 3. p 值到底是什么

**定义**：在 H0 成立的前提下，观察到当前结果或更极端结果的概率。

**正确解读**：
- p < 0.05 → "如果没差异，出现这么大差异的概率 < 5%" → 认为有差异
- p > 0.05 → "出现这么大差异不算罕见" → 不足以说有差异

**错误解读**：
- ❌ "p 值是 H0 为真的概率"
- ❌ "p < 0.05 说明差异很大"
- ❌ "p > 0.05 说明没差异"（只是不足以证明有差异）

### 4. 置信区间

**定义**：真值有 95% 概率在这个区间内（更严谨：重复抽样 95% 的区间包含真值）。

**与 p 值的关系**：
- 95% 置信区间不含 0（差异场景）→ p < 0.05
- 95% 置信区间含 0 → p > 0.05

**为什么置信区间更好**：
- 不仅告诉你"显不显著"，还告诉你"差异多大"
- p 值只说"有差异"，不说"差异多大"

### 5. 单尾 vs 双尾

| 类型 | H1 | 适用 |
|------|----|------|
| 双尾 | A ≠ B | 通用（默认） |
| 单尾 | A > B 或 A < B | 有方向预期 |

**注意**：默认用双尾，除非有强方向预期。单尾更容易"显著"，但容易自欺。

## 二、方法：常用检验

### 1. 检验选择决策表

| 场景 | 数据类型 | 检验方法 |
|------|---------|---------|
| 单组 vs 已知值 | 连续，正态 | 单样本 t 检验 |
| 两组对比 | 连续，正态 | 独立样本 t 检验 |
| 两组对比 | 连续，非正态 | Mann-Whitney U |
| 配对对比 | 连续 | 配对 t 检验 |
| 多组对比 | 连续 | ANOVA |
| 频率/比例 | 计数 | 卡方检验 |
| 相关性 | 连续 | Pearson/Spearman |

### 2. t 检验（最常用）

**场景**：比较两组均值是否有差异。

**例**：A/B 测试，A 组转化率 vs B 组转化率。

**类型**：
- 独立样本 t 检验：两组不同人
- 配对 t 检验：同一组人前后对比

**前提**：
- 数据近似正态（或样本量足够大靠 CLT）
- 两组方差近似相等（否则用 Welch t 检验）

### 3. 解读结果的标准动作

```
1. 看 p 值：是否 < α（通常 0.05）
2. 看置信区间：差异范围
3. 看效应量：差异多大（不只是显不显著）
4. 结合业务：差异虽显著但业务意义大吗？
```

**关键认知**：统计显著 ≠ 业务显著。10 万人样本，0.1% 差异也显著，但业务上可能没意义。

### 4. 多重比较问题

**问题**：测 20 个假设，即使全无差异，平均有 1 个会"显著"（0.05×20）。

**解决**：
- Bonferroni 校正：α / 检验次数（如 0.05/20 = 0.0025）
- FDR 控制：控制"假发现率"

### 5. 常见误区

| 误区 | 正确理解 |
|------|---------|
| p < 0.05 = 有差异 | 只是"不足以说没差异" |
| p > 0.05 = 没差异 | 只是"证据不足"，不是"证明没差异" |
| 显著 = 重要 | 统计显著 ≠ 业务重要 |
| 多测不校正 | 多重比较会假显著 |
| 看到显著就停 | 提前停止会偏结果 |

## 三、代码示例要点

```python
from scipy import stats
import numpy as np

# A/B 测试：两组转化金额
group_a = np.random.normal(100, 20, 1000)
group_b = np.random.normal(105, 20, 1000)

# t 检验
t_stat, p_value = stats.ttest_ind(group_a, group_b)
print(f"t={t_stat:.3f}, p={p_value:.4f}")

# 解读
if p_value < 0.05:
    print("差异显著")
    # 看效应量
    diff = group_b.mean() - group_a.mean()
    print(f"差异: {diff:.2f}")
else:
    print("差异不显著")

# 置信区间
import statsmodels.stats.api as sms
cm = sms.CompareMeans(sms.DescrStatsW(group_b), sms.DescrStatsW(group_a))
print("95% CI:", cm.tconfint_diff())

# 正态性检验（决定用 t 还是 Mann-Whitney）
stat, p = stats.shapiro(group_a[:500])  # 样本量限制
print("正态性 p:", p)
```

## 五、今日小结

- 假设检验 = 反证法：假设没差异，看差异是否罕见
- p 值：H0 成立时观察到当前结果的概率
- p < 0.05 → 拒绝 H0，认为有差异
- 两类错误：α（误报）、β（漏报）
- 统计显著 ≠ 业务显著
- 多重比较需校正
