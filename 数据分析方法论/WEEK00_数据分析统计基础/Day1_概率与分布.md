# Day1 · 概率与分布

> 概率是数据分析的"母语"。不懂概率，看不懂统计结果。

---

## 一、原理：概率到底是什么

### 1. 三种理解

| 理解 | 含义 | 例子 |
|------|------|------|
| 频率派 | 重复多次，事件发生的比例 | 投硬币 1000 次，正面约 500 次 |
| 古典派 | 等可能事件的比值 | 骰子 6 面，每面概率 1/6 |
| 主观派 | 基于信息的信念程度 | "我认为明天涨的概率 70%" |

**数据分析常用频率派**：概率 = 长期频率的极限。

### 2. 核心概念

| 概念 | 大白话 | 例子 |
|------|--------|------|
| 随机变量 | 结果不确定的量 | 投硬币结果 X |
| 概率分布 | 所有可能值 + 各自概率 | {正面:0.5, 反面:0.5} |
| 期望 E(X) | 长期平均值 | 投骰子期望 = 3.5 |
| 方差 Var(X) | 波动大小 | 收入方差大 = 贫富差距大 |

**直觉**：
- 期望 = "平均会怎样"
- 方差 = "有多不确定"

### 3. 离散 vs 连续

| 类型 | 取值 | 例子 | 分布 |
|------|------|------|------|
| 离散 | 可数 | 投硬币、订单数 | 二项/泊松 |
| 连续 | 不可数 | 身高、金额 | 正态/对数正态 |

## 二、四大常用分布

### 1. 正态分布（最重要）

**形状**：钟形，对称，中间多两端少。

**为什么重要**：中心极限定理（Day3 详解）——大量独立因素叠加的结果都近似正态。

**参数**：
- μ（mu）：均值，决定中心位置
- σ（sigma）：标准差，决定胖瘦

**68-95-99.7 法则**：
- ±1σ 覆盖 68% 数据
- ±2σ 覆盖 95% 数据
- ±3σ 覆盖 99.7% 数据

**应用**：
- 标准化（z-score）：z = (x - μ) / σ
- 异常检测：|z| > 3 视为异常
- 假设检验的基础

**什么样的数据近似正态**：
- 人的身高、考试成绩、测量误差
- 注意：金额、收入通常**不**是正态（是正偏）

### 2. 二项分布

**场景**：n 次独立试验，每次成功概率 p，问成功几次。

**例子**：
- 投 10 次硬币，正面次数
- 100 个用户，转化几个

**参数**：n（次数）、p（成功概率）
**期望**：np
**方差**：np(1-p)

**应用**：
- 转化率分析
- A/B 测试（两组成功率对比）

### 3. 泊松分布

**场景**：单位时间/空间内，某事件发生次数。

**例子**：
- 每分钟客服来电数
- 每天网站访问数
- 每小时交易笔数

**参数**：λ（lambda，平均发生次数）
**期望 = 方差 = λ**

**特征**：发生是独立的、随机的时间点。

**应用**：
- 排队论（客服排班）
- 异常检测（某时段发生数远超 λ）

### 4. 对数正态分布

**场景**：数据本身正偏长尾，但**取对数后**近似正态。

**例子**：
- 收入、金额、房价、网站访问量
- 这些数据"小值多、大值少、有极端大值"

**为什么**：这些量是"乘性增长"（如复利），乘积取对数变加法 → 正态。

**应用**：
- 金额分析先取对数再分析
- 长尾数据用中位数而非均值

## 三、方法：怎么用

### 1. 判断数据服从什么分布

| 步骤 | 动作 |
|------|------|
| 1 | 画直方图，看形状 |
| 2 | 对称钟形 → 可能正态 |
| 3 | 长尾右偏 → 可能对数正态（取对数再看） |
| 4 | 计数数据 → 二项/泊松 |
| 5 | 用 QQ 图验证（点近似在直线上 = 符合分布） |

### 2. 分布的应用决策

| 场景 | 用什么分布 | 注意 |
|------|-----------|------|
| 异常检测（正态数据） | 3σ / z-score | 数据要近似正态 |
| 异常检测（长尾数据） | 取对数后用 3σ，或用 IQR | 不能直接用 3σ |
| 转化率分析 | 二项分布 | 算置信区间 |
| 事件计数 | 泊松分布 | 判断是否异常高频 |

### 3. 常见误区

- **金额用均值**：金额长尾，均值被极端值拉高，应该用中位数
- **长尾数据用 3σ**：3σ 假设正态，长尾数据会把正常大值当异常
- **小样本下结论**：n 太小时分布判断不准

## 四、代码示例要点

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 正态分布
data = np.random.normal(100, 15, 10000)  # 均值100, 标准差15
plt.hist(data, bins=50); plt.show()
# z-score
z = (data - 100) / 15
# 异常：|z| > 3

# 二项分布
n, p = 100, 0.1
binom = stats.binom(n, p)
print("期望:", n*p, " 实际:", binom.mean())

# 泊松分布
lam = 5  # 每分钟平均5个电话
poisson = stats.poisson(lam)
# 某分钟来10个，异常吗？
print("P(>=10):", 1 - poisson.cdf(9))

# 对数正态
amounts = np.random.lognormal(3, 1, 10000)  # 金额
print("均值:", amounts.mean(), " 中位数:", np.median(amounts))
# 均值 >> 中位数 = 长尾
```

## 六、今日小结

- 概率 = 长期频率的极限
- 期望 = "平均会怎样"，方差 = "有多不确定"
- 正态分布是统计学的基石（CLT 让它无处不在）
- 金额/收入是长尾，用对数正态理解，用中位数描述
- 判断分布：直方图 + QQ 图
