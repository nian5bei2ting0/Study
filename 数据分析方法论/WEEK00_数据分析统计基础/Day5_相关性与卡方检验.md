# Day5 · 相关性与卡方检验

> 相关性回答"两个变量有没有关系"。卡方回答"两个分类变量是否独立"。

---

## 一、原理：相关性

### 1. 相关性是什么

**定义**：两个变量一起变化的程度。
- 正相关：A 涨 B 也涨
- 负相关：A 涨 B 跌
- 无相关：A 变化与 B 无关

**关键认知**：相关 ≠ 因果。
- 冰淇淋销量和溺水率正相关
- 但不是因果——夏天（C）同时影响两者
- C 是混淆变量

### 2. 三种相关系数

| 系数 | 适用 | 检测关系 | 范围 |
|------|------|---------|------|
| Pearson | 连续变量，线性关系 | 线性 | [-1, 1] |
| Spearman | 连续/有序，单调关系 | 单调（含非线性） | [-1, 1] |
| Kendall | 有序变量 | 一致性 | [-1, 1] |

**选择**：
| 数据特点 | 用什么 |
|---------|--------|
| 线性关系 + 无异常值 | Pearson |
| 单调但非线性 / 有异常值 | Spearman |
| 有序分类 | Kendall |

### 3. Pearson 相关系数

**公式直觉**：r = 协方差 / (σ_A × σ_B)
- 协方差：A 和 B 一起偏离均值的程度
- 除以两个标准差：标准化到 [-1, 1]

**解读**：
| r 值 | 相关性 |
|------|--------|
| ±0.9+ | 极强 |
| ±0.7~0.9 | 强 |
| ±0.4~0.7 | 中等 |
| ±0.2~0.4 | 弱 |
| 0~0.2 | 极弱/无 |

**前提**：
- 线性关系（散点图看是不是直线）
- 无显著异常值（Pearson 对异常敏感）
- 近似正态（严格假设）

### 4. Spearman 相关系数

**原理**：用秩次（排名）代替原值算 Pearson。

**优点**：
- 抗异常值（用排名）
- 检测单调关系（不限于线性）

**例**：x = [1,2,3,100]，y = [10,20,30,1000]
- Pearson：被 100 和 1000 主导
- Spearman：排名都是 1,2,3,4 → r=1（完美单调）

### 5. 相关 ≠ 因果的常见陷阱

| 陷阱 | 说明 |
|------|------|
| 混淆变量 | C 同时影响 A 和 B |
| 反向因果 | 以为是 A→B，实际 B→A |
| 巧合 | 数据多了总能找到相关 |
| 中介变量 | A→C→B，A 和 B 相关但 A 不直接导致 B |

**如何接近因果**：
- 随机实验（A/B 测试）——金标准
- 控制混淆变量（分层分析）
- 因果推断方法（WEEK02 Day5）

## 二、原理：卡方检验

### 1. 卡方检验是什么

**场景**：两个分类变量是否独立。

**例**：
- 性别（男/女）与 是否购买（是/否）有关吗？
- 渠道（A/B/C）与 是否流失（是/否）有关吗？

### 2. 列联表

| | 购买 | 不购买 | 合计 |
|---|------|--------|------|
| 男 | 60 | 40 | 100 |
| 女 | 50 | 50 | 100 |
| 合计 | 110 | 90 | 200 |

**问题**：男和女的购买率差异显著吗？

### 3. 卡方检验原理

```
1. 假设独立（H0：性别与购买无关）
2. 算"如果独立，每格应该是多少"（期望值）
3. 比较"实际值"与"期望值"的差异
4. 差异大 → 拒绝 H0 → 不独立
```

**期望值**：E = (行合计 × 列合计) / 总数
- 男购买期望 = 100 × 110 / 200 = 55
- 实际 60 vs 期望 55

**卡方统计量**：χ² = Σ (实际 - 期望)² / 期望

### 4. 适用条件

- 每格期望值 ≥ 5（否则用 Fisher 精确检验）
- 样本独立
- 分类变量

## 三、方法：怎么用

### 1. 相关性分析标准流程

```
1. 画散点图，看关系形态
   - 线性？非线性？无关系？
2. 选系数
   - 线性 → Pearson
   - 单调非线性/有异常 → Spearman
3. 算相关系数 + p 值
   - r 衡量强度，p 衡量显著性
4. 检查混淆变量
   - 相关是真的还是第三变量导致？
5. 业务解读
   - 相关性大小是否有业务意义？
```

### 2. 相关性矩阵

多变量两两相关，用热力图可视化。

**用途**：
- 找高度相关的特征（多重共线性）
- 找与目标相关的特征（特征选择）

**注意**：Pearson 矩阵只看线性关系，可能漏掉非线性。

### 3. 卡方检验流程

```
1. 建列联表
2. 检查每格期望值 ≥ 5
3. 算卡方统计量 + p 值
4. p < 0.05 → 不独立（有关联）
5. 看具体哪格差异大（标准化残差）
```

### 4. 相关性应用的常见场景

| 场景 | 方法 |
|------|------|
| 特征选择 | 与目标的相关性排序 |
| 多重共线性检查 | 特征间相关性 |
| 业务归因初探 | 指标间相关性 |
| 分群特征 | 群体间差异（卡方） |

### 5. 常见误区

- **看到相关就说因果**：最常见错误
- **Pearson 用于非线性**：会低估关系
- **忽略异常值**：Pearson 被异常主导
- **小样本下高相关**：n 小时相关不稳定
- **卡方每格 < 5 还用**：结果不可靠

## 四、代码示例要点

```python
import numpy as np
import pandas as pd
from scipy import stats

# Pearson vs Spearman
x = np.random.normal(0, 1, 100)
y = x * 2 + np.random.normal(0, 0.5, 100)  # 线性
print("Pearson:", stats.pearsonr(x, y)[0])
print("Spearman:", stats.spearmanr(x, y)[0])

# 非线性关系
y2 = x ** 2  # 非线性
print("非线性 Pearson:", stats.pearsonr(x, y2)[0])  # 接近0
print("非线性 Spearman:", stats.spearmanr(x, y2)[0])  # 也接近0（非单调）

# 卡方检验
table = np.array([[60, 40], [50, 50]])
chi2, p, dof, expected = stats.chi2_contingency(table)
print(f"卡方={chi2:.3f}, p={p:.4f}")
print("期望值:\n", expected)

# 相关性矩阵
df = pd.DataFrame({'a': x, 'b': y, 'c': y2})
print(df.corr())  # Pearson
```

## 六、今日小结

- 相关性量化两变量关系，范围 [-1, 1]
- Pearson 看线性，Spearman 看单调，Kendall 看有序
- 相关 ≠ 因果，警惕混淆变量
- 卡方检验判断两个分类变量是否独立
- 相关性矩阵 + 热力图是多变量分析利器
