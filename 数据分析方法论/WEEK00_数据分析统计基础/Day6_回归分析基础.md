# Day6 · 回归分析基础

> 回归是"用关系做预测和解释"的核心方法。它既是统计方法，也是建模思想的起点。

---

## 一、原理：回归在做什么

### 1. 回归的本质

**目标**：找一条线（或面），最好地拟合数据，用来预测和解释。

**两类用途**：
| 用途 | 问题 | 例子 |
|------|------|------|
| 解释 | 哪些因素影响 Y？影响多大？ | 广告投入对销售额的影响 |
| 预测 | 给定 X，Y 是多少？ | 预测下月销售额 |

### 2. 线性回归

**模型**：Y = β₀ + β₁X + ε
- β₀：截距（X=0 时 Y 的值）
- β₁：斜率（X 变 1 个单位，Y 变多少）
- ε：误差（模型没解释的部分）

**最小二乘法**：找 β₀、β₁ 使 Σ(Y实际 - Y预测)² 最小。

**直觉**：让所有点到直线的"垂直距离平方和"最小。

### 3. R²（决定系数）

**定义**：模型解释了 Y 变异的多少比例。

**范围**：[0, 1]
- 0：模型没解释任何变异
- 1：模型完美解释
- 0.8：解释了 80% 的变异

**解读**：
| R² | 评价 |
|----|------|
| < 0.3 | 拟合差 |
| 0.3-0.6 | 中等 |
| 0.6-0.9 | 较好 |
| > 0.9 | 很好（小心过拟合） |

**注意**：R² 高不代表模型对，可能过拟合或漏掉非线性。

### 4. 系数的解读

**β₁ 的含义**：X 增加 1 个单位，Y 平均增加 β₁（其他变量不变）。

**统计显著性**：看 β₁ 的 p 值
- p < 0.05 → 系数显著不为 0 → X 对 Y 有影响
- p > 0.05 → 不足以说 X 影响 Y

**置信区间**：β₁ 的 95% 置信区间，包含真实值的概率。

### 5. 逻辑回归

**场景**：Y 是二分类（0/1），如是否流失、是否欺诈。

**模型**：log(P(Y=1) / (1-P(Y=1))) = β₀ + β₁X
- 即对数几率是线性的

**输出**：概率 P(Y=1)，范围 [0, 1]

**系数解读**：
- β₁ > 0：X 增加时，Y=1 的概率增加
- β₁ < 0：X 增加时，Y=1 的概率减少
- 不能直接说"增加 β₁"，要用 odds ratio = e^β₁

### 6. 回归的前提假设（线性回归）

| 假设 | 含义 | 违反后果 |
|------|------|---------|
| 线性 | Y 与 X 线性相关 | 拟合差 |
| 独立 | 观测值独立 | 标准误错 |
| 同方差 | 残差方差恒定 | 标准误错 |
| 正态残差 | 残差近似正态 | 推断不准 |
| 无多重共线 | X 之间不高度相关 | 系数不稳定 |

**检查**：残差图、Q-Q 图、VIF（方差膨胀因子）。

## 二、方法：怎么用

### 1. 回归分析标准流程

```
1. 明确目标：解释还是预测？
2. 画散点图，看是否线性
3. 拟合模型
4. 看整体：R²、F 检验
5. 看系数：p 值、置信区间
6. 检查假设：残差分析
7. 业务解读：系数含义
```

### 2. 线性 vs 逻辑回归选择

| Y 类型 | 方法 |
|--------|------|
| 连续（金额、销量） | 线性回归 |
| 二分类（是否、流失） | 逻辑回归 |
| 计数（次数） | 泊松回归 |
| 多分类 | 多项逻辑回归 |

### 3. 多重共线性

**问题**：X 之间高度相关 → 系数不稳定、难解读。

**检测**：
- 相关性矩阵：相关 > 0.8
- VIF（方差膨胀因子）：VIF > 5/10 有问题

**解决**：
- 删一个相关变量
- 用 PCA 降维
- 用正则化（岭回归/Lasso）

### 4. 残差分析

**残差 = 实际值 - 预测值**，残差图判断假设是否成立。

| 残差图形态 | 问题 |
|-----------|------|
| 随机散布 | ✓ 假设成立 |
| 有曲线 | 非线性，漏了项 |
| 漏斗形 | 异方差 |
| 有趋势 | 自相关 |

### 5. 常见误区

- **R² 高就满意**：可能过拟合或漏假设
- **不看残差**：假设可能违反
- **系数大就重要**：要看显著性 + 量纲
- **相关变量都塞进去**：多重共线性
- **用线性回归预测分类**：应该用逻辑回归

## 三、代码示例要点

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.metrics import r2_score

# 线性回归（statsmodels，含统计推断）
X = np.random.normal(0, 1, 200)
Y = 2 + 3*X + np.random.normal(0, 1, 200)
X_with_const = sm.add_constant(X)
model = sm.OLS(Y, X_with_const).fit()
print(model.summary())  # 看系数、p值、R²

# 逻辑回归
from sklearn.datasets import make_classification
X, y = make_classification(n_samples=500, n_features=3, random_state=42)
log_model = LogisticRegression().fit(X, y)
print("系数:", log_model.coef_)
print("概率:", log_model.predict_proba(X[:5]))

# 残差分析
residuals = Y - model.predict(X_with_const)
import matplotlib.pyplot as plt
plt.scatter(model.predict(X_with_const), residuals)
plt.axhline(0, color='r')
# 随机散布 = 假设成立

# VIF 检查多重共线性
from statsmodels.stats.outliers_influence import variance_inflation_factor
```

## 五、今日小结

- 线性回归：Y 连续；逻辑回归：Y 二分类
- R² 衡量模型解释力，[0,1]
- 系数 p 值判断显著性，置信区间看范围
- 五大假设要检查（残差分析）
- 多重共线性用 VIF 检测
