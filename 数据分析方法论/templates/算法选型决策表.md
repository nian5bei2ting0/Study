## 决策树参考

```

├── 分类
│   ├── 小数据 + 可解释 → 逻辑回归 / 决策树

│   ├── 高维稀疏 → 朴素贝叶斯 / SVM
│   ├── 图像 → CNN
│   └── 极致精度 + 数据足 → 集成 / 深度学习
├── 回归
│   ├── 线性 + 可解释 → 线性回归 / 岭 / Lasso
│   ├── 非线性 + 表格 → 树模型

├── 聚类
│   ├── 球形 → KMeans
│   ├── 任意形状 → DBSCAN
│   └── 层次 → 层次聚类
└── 异常检测
    ├── 单变量 → 3σ / IQR
    └── 多变量 → 孤立森林 / LOF
```
