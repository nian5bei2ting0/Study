# Day3 · 预测性分析方法论

> 预测性分析回答"会发生什么"。预测是辅助决策，不是替决策。

---

## 一、方法论框架

### 1. 预测目标定义

动手前明确：

| 问题 | 例子 |
|------|------|
| 预测什么？ | 下月销量 / 用户是否流失 |
| 预测多远？ | 下周 / 下月 / 下季 |
| 预测多准？ | MAE < 10% / AUC > 0.8 |
| 给谁用？ | 供应链 / 客户成功 |
| 用了做什么？ | 补货 / 召回 |

**没有行动意图的预测没有意义**。

### 2. 预测类型

| 类型 | 例子 | 方法 |
|------|------|------|
| 点预测 | 下月销量 1000 | 回归 |
| 区间预测 | 下月销量 800-1200 | 回归 + 置信区间 |
| 概率预测 | 流失概率 0.7 | 分类 |
| 排序预测 | 风险排名 Top 100 | 分类 + 排序 |
| 趋势预测 | 未来 3 月趋势 | 时序 |

### 3. 特征工程在预测中的特殊考量

**时序无泄漏**：
- 特征只能用预测时点之前的数据
- 滞后特征：lag_1, lag_7, lag_30
- 滑动窗口：近 7 天均值
- 不能用"当月均值"预测"当月"

**特征可得性**：
- 预测时点能否拿到这个特征？
- 例：预测下月销量，"下月促销计划"可能拿不到
- → 用"已确定的促销计划"或"历史促销模式"

**特征稳定性**：
- PSI 监控
- 不稳定特征要降权或剔除

### 4. 预测不确定性

**为什么需要不确定性**：
- 点预测 1000，实际可能 500-1500
- 决策者需要知道区间来备安全库存

**方法**：
- 分位数回归：预测 P10/P50/P90
- Bootstrap：重采样估计区间
- 贝叶斯方法：后验分布

**表达**：
- 点预测 + 置信区间：1000 [800, 1200]
- 概率预测：流失概率 0.7 ± 0.05

### 5. 预测 vs 预言

| | 预测 | 预言 |
|---|------|------|
| 目的 | 辅助决策 | 替决策 |
| 态度 | 提供可能 | 给定结论 |
| 不确定性 | 显式表达 | 隐藏 |
| 行动 | 人决策 | 自动执行 |

**预测是工具，不是神谕**。

### 6. 预测评估

| 指标 | 适用 |
|------|------|
| MAE/RMSE | 回归 |
| MAPE | 百分比误差 |
| AUC/F1 | 分类 |
| 分位数损失 | 区间预测 |
| 时序回测 | 时序 |

**时序回测**：在历史时间点"假装预测"，对比实际值。

## 二、案例复盘：某供应链需求预测

### 1. 业务背景
- 200 家门店，每周补货
- 目标：预测下周各门店各品类销量
- 行动：自动补货建议 + 人工审核

### 2. 预测目标定义

| 项 | 定义 |
|----|------|
| 预测什么 | 门店×品类×周销量 |
| 预测多远 | 提前 1 周 |
| 预测多准 | MAPE < 25% |
| 给谁用 | 供应链团队 |
| 行动 | 补货量 = 预测 × 安全系数 |

### 3. 特征工程

**时序特征**：
- lag_1（上周）、lag_4（上月同周）、lag_52（去年同周）
- 近 4 周滑动均值
- 近 13 周滑动均值

**日历特征**：
- 星期几、月初/月末
- 节假日、促销日

**门店特征**：
- 门店类型、面积、地区

**防泄漏检查**：
- lag_1 用上周数据 ✓
- 不能用"本周均值" ✗
- 节假日特征用"已知节假日" ✓

### 4. 模型选择

- ARIMA：单变量，无法加促销 → 淘汰
- Prophet：可加特征但单序列 → 维护成本高
- LightGBM：多特征 + 表格 + 可解释 → 选用

### 5. 不确定性表达

**分位数预测**：
- P50（中位预测）：100 件
- P10（悲观）：80 件
- P90（乐观）：130 件

**补货决策**：
- 基础补货 = P50
- 安全库存 = P90 - P50 = 30 件
- → 补 130 件（防缺货）

**关键品类**（缺货代价高）：用 P90
**普通品类**（库存成本高）：用 P50

### 6. 评估

| 指标 | 值 | 判定 |
|------|----|------|
| MAPE | 22% | 达标 |
| P10 覆盖率 | 88% | 偏低（应 90%） |
| P90 覆盖率 | 92% | 达标 |

**P10 覆盖率偏低**：悲观预测还不够悲观，调模型

### 7. 教训
- 没有不确定性表达的预测，决策者不敢用
- 安全库存基于 P90，不是拍脑袋
- 关键品类和普通品类用不同分位数
- 时序回测发现 P10 偏乐观，及时调整

## 三、思考练习

1. 定义你的一个预测目标：预测什么、多远、多准、给谁、做什么。
2. 列出你的特征，检查有无时序泄漏。
3. 设计不确定性表达方案：点预测 + 区间。

---

## 四、今日小结

- 预测目标要含行动意图
- 特殊考量：时序无泄漏、特征可得性、稳定性
- 不确定性要显式表达（区间/概率）
- 预测是辅助决策，不是替决策
- 时序回测是时序预测的评估方法
