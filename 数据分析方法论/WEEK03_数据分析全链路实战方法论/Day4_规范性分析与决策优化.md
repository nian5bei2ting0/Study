# Day4 · 规范性分析与决策优化

> 规范性分析回答"该怎么做"。从分析到决策的最后一步。

---

## 一、方法论框架

### 1. 规范性分析 = 描述 + 诊断 + 预测 + 优化

```
描述：现状是什么
  ↓
诊断：为什么这样
  ↓
预测：不改变会怎样
  ↓
规范：改变的话该怎么做（优化）
```

**规范性分析是分析的最高层**：不只是给洞察，还给最优行动方案。

### 2. 优化三要素

| 要素 | 含义 | 例子 |
|------|------|------|
| 目标函数 | 要最大化/最小化什么 | 最小化总成本 |
| 决策变量 | 可以调整什么 | 各路线运量 |
| 约束条件 | 限制是什么 | 容量、时间、预算 |

**没有约束的优化是空谈，没有目标的优化是乱调**。

### 3. 优化问题分类

| 类型 | 特点 | 求解方法 |
|------|------|---------|
| 线性规划 | 目标和约束都是线性 | 单纯形法 |
| 整数规划 | 决策变量是整数 | 分支定界 |
| 非线性规划 | 含非线性关系 | 梯度法 |
| 多目标优化 | 多个目标冲突 | 帕累托前沿 |
| 启发式 | 无法精确求解 | 遗传算法、模拟退火 |

### 4. 求解思路

**精确求解**：
- 问题规模小、结构清晰
- 用 scipy.optimize / PuLP / OR-Tools
- 得到全局最优

**启发式求解**：
- 问题复杂、规模大
- 用遗传算法、模拟退火
- 得到近似最优

**仿真优化**：
- 系统复杂、有随机性
- 蒙特卡洛仿真
- 评估不同策略的期望效果

### 5. 敏感性分析

**回答**：参数变化时，最优解怎么变？

| 类型 | 方法 |
|------|------|
| 单参数 | 改一个参数看解变化 |
| 多参数 | 同时改多个 |
| 场景分析 | 乐观/中性/悲观场景 |

**价值**：
- 知道解的鲁棒性
- 知道哪些参数最敏感
- 为决策提供安全边际

### 6. 多目标优化

**现实**：业务常有多个冲突目标
- 成本 vs 服务水平
- 短期收益 vs 长期价值
- 风险 vs 收益

**方法**：
- 加权求和：转成单目标（权重难定）
- 帕累托前沿：找非劣解集合
- 约束法：一个目标主优化，其他做约束

### 7. 从分析到决策的桥梁

| 分析产出 | 决策需要 |
|---------|---------|
| 洞察 | 行动方案 |
| 预测 | 最优选择 |
| 优化解 | 可执行方案 |
| 敏感性 | 风险评估 |

**规范性分析把"分析"变成"建议"**。

## 二、案例复盘：某物流路径优化

### 1. 业务背景
- 50 辆车，每天配送 500 个订单到 200 个点
- 现状：司机凭经验规划，总里程 5000 公里/天
- 目标：最小化总里程

### 2. 优化建模

**目标函数**：
```
min ΣΣ x_ij × d_ij
（x_ij：车是否走 i→j 路段；d_ij：距离）
```

**决策变量**：
- 每辆车走哪些点、什么顺序

**约束条件**：
- 每车容量 ≤ 载重上限
- 每点必须被访问一次
- 每车工作时长 ≤ 8 小时
- 时间窗：部分点有时效要求

### 3. 求解

**问题性质**：车辆路径问题（VRP），NP-hard
**方法**：启发式（遗传算法 + OR-Tools）

**结果**：
| 方案 | 总里程 | 车辆数 |
|------|--------|--------|
| 人工经验 | 5000 | 50 |
| 优化解 | 3800 | 47 |
| 节省 | 1200（24%） | 3 |

### 4. 敏感性分析

**订单量变化**：
| 订单量 | 总里程 | 车辆数 |
|--------|--------|--------|
| 400 | 3100 | 38 |
| 500 | 3800 | 47 |
| 600 | 4600 | 56 |

**结论**：订单量增 20%，里程增 21%，车辆增 19%——线性扩展

**时间窗约束**：
| 时间窗比例 | 总里程 |
|-----------|--------|
| 0% | 3500 |
| 30% | 3800 |
| 60% | 4500 |

**结论**：时间窗约束越严，里程越高——需权衡

### 5. 多目标权衡

**目标**：里程 vs 时效（时间窗满足率）
- 方案 A：里程 3800，时效 90%
- 方案 B：里程 4200，时效 98%
- 方案 C：里程 3500，时效 85%

**决策**：选 B（时效优先，客户体验重要）

### 6. 落地

**不是直接用优化解**：
- 优化解是"建议"
- 司机可调整（路况、临时加单）
- 系统每日生成建议 + 人工审核

### 7. 教训
- 优化不是替决策，是给建议
- 敏感性分析让决策者知道风险
- 多目标要业务定优先级
- 优化解 + 人工审核 = 可落地方案

## 三、思考练习

1. 把你的一个业务问题写成优化三要素（目标/变量/约束）。
2. 对你的方案做敏感性分析：改一个参数看结果变化。
3. 列出你的业务中的 2 个冲突目标，设计权衡方案。

## 四、今日小结

- 规范性分析 = 描述 + 诊断 + 预测 + 优化
- 优化三要素：目标函数、决策变量、约束
- 精确求解 vs 启发式 vs 仿真
- 敏感性分析评估鲁棒性
- 多目标用帕累托前沿或约束法
- 优化解 + 人工审核 = 可落地
