# WEEK03 · 数据分析全链路实战方法论

> **本周目标**：掌握四类分析（描述/诊断/预测/规范）的方法论，能针对不同业务目标选择正确分析路径。
> **核心问题**：拿到一个分析需求，如何判断是哪类分析，用什么方法，产出什么？

---

## 本周路线

| Day | 主题 | 方法论核心 | 案例复盘 |
|-----|------|-----------|---------|
| 1 | 描述性分析方法论 | 现状盘点 / 对比基准 / 结构拆解 | 某电商月度经营分析 |
| 2 | 诊断性分析方法论 | 根因分析 / 下钻 / 假设验证 | 某产品转化率下降诊断 |
| 3 | 预测性分析方法论 | 预测目标 / 特征 / 评估 / 置信度 | 某供应链需求预测 |
| 4 | 规范性分析与决策优化 | 优化目标 / 约束 / 求解 / 敏感性 | 某物流路径优化 |
| 5 | 时间序列分析方法论 | 分解 / 趋势 / 季节 / 异常 / 预测 | 某能源负荷预测 |
| 6 | 用户分析方法论 | cohort / RFM / 路径 / 生命周期 | 某电商用户分层运营 |
| 7 | 综合复盘与端到端案例 | 四类分析协同 / 全链路图 | 某业务从描述到规范的演进 |

---

## 学完本周你能做到

- [ ] 区分四类分析并选择正确方法
- [ ] 做一次完整的描述性分析（现状 + 对比 + 结构）
- [ ] 做一次完整的诊断性分析（根因定位）
- [ ] 设计预测性分析方案并评估不确定性
- [ ] 把业务问题转化为优化问题
- [ ] 做时序分解和异常检测
- [ ] 做用户分层和生命周期分析
