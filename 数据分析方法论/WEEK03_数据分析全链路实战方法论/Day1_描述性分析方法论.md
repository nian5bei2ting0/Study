# Day1 · 描述性分析方法论

> 描述性分析回答"发生了什么"。看似简单，做精了不简单。

---

## 一、方法论框架

### 1. 描述性分析的核心三要素

| 要素 | 含义 | 产出 |
|------|------|------|
| 现状 | 当前是什么状态 | 核心指标值 |
| 对比 | 和谁比、差多少 | 同比/环比/目标比 |
| 结构 | 怎么构成的 | 维度拆解 |

**没有对比的描述没有意义**："GMV 1000 万"——是高是低？要对比才知道。

### 2. 对比基准选择

| 基准类型 | 适用 | 注意 |
|---------|------|------|
| 同比（YoY） | 有季节性业务 | 消除季节性 |
| 环比（MoM） | 短期趋势 | 受季节性干扰 |
| 目标比 | 有 KPI | 目标是否合理 |
| 行业比 | 竞争分析 | 口径要一致 |
| 历史均值 | 长期趋势 | 选多长周期 |

**选择原则**：
- 有季节性 → 同比
- 看短期 → 环比
- 看达成 → 目标比
- 看竞争力 → 行业比

### 3. 结构拆解

**维度拆解**：按地区/品类/渠道/用户群
```
GMV = 华东 + 华南 + 华北 + ...
     = 服装 + 3C + 食品 + ...
     = APP + 小程序 + Web + ...
```

**指标拆解**：杜邦分解
```
GMV = 流量 × 转化率 × 客单价
```

**拆解原则**：
- MECE（不重不漏）
- 拆到可行动（能定位责任主体）
- 不要拆太细（超过 3 层难理解）

### 4. 仪表盘设计原则

| 原则 | 说明 |
|------|------|
| 从总到分 | 顶层指标 → 一级拆解 → 二级拆解 |
| 异常高亮 | 红/绿色标注异常 |
| 行动导向 | 每个指标关联责任人 |
| 一屏一主题 | 不要一屏塞 50 个指标 |
| 时间可调 | 支持切换时间范围 |

### 5. 描述性分析的常见错误

- **只报现状不对比**："GMV 1000 万"——然后呢？
- **拆解不穷尽**：只看流量不看客单
- **拆太细**：拆到 200 个品类，没人能看
- **对比基准错**：有季节性却用环 比
- **无结论**：堆 30 张图，没有一句话结论

## 二、案例复盘：某电商月度经营分析

### 1. 业务背景
- 月度经营分析会，向管理层汇报
- 数据：上月全站经营数据

### 2. 报告结构

**【一句话结论】**
上月 GMV 1.2 亿，环比 +5% 但同比 -8%，主因是 3C 品类同比 -20%，建议优先复盘 3C 供应链。

**【现状】**
| 指标 | 上月 | 环比 | 同比 |
|------|------|------|------|
| GMV | 1.2 亿 | +5% | -8% |
| 订单量 | 80 万 | +3% | -5% |
| 客单价 | 150 | +2% | -3% |
| 毛利率 | 18% | -1% | -2% |

**【对比】**
- 环比 +5%：短期在恢复
- 同比 -8%：长期在下滑
- → 短期好但长期堪忧

**【结构拆解】**

GMV 按品类：
| 品类 | GMV | 同比 | 占比 |
|------|------|------|------|
| 服装 | 5000 万 | +5% | 42% |
| 3C | 3000 万 | -20% | 25% |
| 食品 | 2000 万 | +3% | 17% |
| 家居 | 2000 万 | +2% | 16% |

**【关键发现】**
- 3C 品类同比 -20%，拖累整体
- 服装、食品、家居都正增长
- → 问题集中在 3C

**【二次下钻】**
3C 品类拆解：
- 手机：同比 -30%（缺货）
- 电脑：同比 -10%
- 配件：同比 +5%
- → 手机缺货是主因

**【建议】**
1. 复盘 3C 手机供应链
2. 暂缓 3C 营销投放（缺货投了也转化不了）
3. 加大服装/食品投放（正增长品类）

### 3. 教训
- 只看环比会误判"在增长"
- 同比暴露长期问题
- 结构拆解定位到 3C，避免"全面优化"
- 二次下钻到"手机缺货"，可行动

---

## 三、思考练习

1. 选你业务的一个核心指标，做现状 + 对比 + 结构拆解。
2. 检查你的对比基准是否合理（季节性、目标、行业）。
3. 写一句话结论，让不懂业务的人也能抓住重点。

---

## 四、今日小结

- 描述性分析三要素：现状 + 对比 + 结构
- 对比基准要选对（季节性用同比）
- 结构拆解要 MECE、可行动
- 仪表盘从总到分、异常高亮
- 没有对比的描述没有意义
