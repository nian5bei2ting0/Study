# Day5 · 时间序列分析方法论

> 时序数据有特殊性：有时间依赖，不能随机切分。方法用错会泄漏。

---

## 一、方法论框架

### 1. 时序分解

**经典分解**：
```
Y(t) = 趋势(T) + 季节(S) + 残差(R)
```

- **趋势**：长期上升/下降
- **季节**：固定周期重复（年/周/日）
- **残差**：去掉趋势和季节后的剩余

**STL 分解**：比经典更灵活，趋势和季节可变。

### 2. 平稳性

**平稳**：均值、方差、自相关不随时间变。

**为什么需要平稳**：很多时序模型（ARIMA）假设平稳。

**检验**：
- ADF 检验：p < 0.05 平稳
- 看时序图：有明显趋势/季节 → 不平稳

**差分**：不平稳转平稳
- 一阶差分：Y(t) - Y(t-1)
- 季节差分：Y(t) - Y(t-s)

### 3. 经典方法对比

| 方法 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| ARIMA | 平稳时序 | 经典、可解释 | 单变量、需调参 |
| 指数平滑 | 有趋势/季节 | 简单 | 单变量 |
| Prophet | 多季节、节假日 | 可加特征、易用 | 单序列 |
| 树模型 + 时序特征 | 多特征 | 灵活、多变量 | 需手工构造特征 |
| LSTM | 复杂时序 | 自动学时序 | 数据量大、黑盒 |

**选择**：
- 单序列、经典 → ARIMA / Prophet
- 多特征 → 树模型 + 时序特征
- 大数据、复杂 → LSTM

### 4. 时序特征构造

| 特征 | 公式 | 含义 |
|------|------|------|
| 滞后 | lag_1, lag_7, lag_52 | 历史值 |
| 滑动均值 | rolling_mean_7 | 近期趋势 |
| 滑动标准差 | rolling_std_7 | 近期波动 |
| 环比 | (Y_t - Y_{t-1}) / Y_{t-1} | 变化率 |
| 同比 | (Y_t - Y_{t-s}) / Y_{t-s} | 周期对比 |
| 扩展均值 | expanding_mean | 长期均值 |

**防泄漏**：特征只能用 t 之前的数据。

### 5. 时序异常检测

| 方法 | 适用 |
|------|------|
| 移动平均残差 | 趋势数据 |
| STL 残差 | 有季节 |
| 3σ / IQR | 残差序列 |
| 孤立森林 | 多维时序 |
| 控制图 | 工业场景 |

### 6. 时序评估

**不能用随机 split**：
- 随机 split 会泄漏未来信息
- 用时序 split：训练用前 80%，测试用后 20%

**回测**：
- 在历史多个时点"假装预测"
- 滚动窗口：每次用前 N 天预测下 1 天
- 评估所有预测的平均误差

**指标**：
- MAE / RMSE / MAPE
- MASE（相对朴素预测）

## 二、案例复盘：某能源负荷预测

### 1. 业务背景
- 某电网，预测明日各时段用电负荷
- 目标：MAPE < 5%
- 行动：发电计划

### 2. 数据特点

- 每小时一个点，一天 24 个点
- 多季节：日季节（24h）、周季节（7d）、年季节（365d）
- 影响因素：温度、节假日、特殊事件

### 3. STL 分解

```
负荷 = 趋势 + 日季节 + 年季节 + 残差
```

**发现**：
- 趋势：缓慢上升
- 日季节：白天高、夜间低
- 年季节：夏冬高、春秋低
- 残差：有突发尖峰（极端天气）

### 4. 特征工程

**时序特征**：
- lag_24（昨日同时段）、lag_168（上周同时段）
- rolling_mean_24、rolling_mean_168

**外部特征**：
- 温度（天气预报可得）
- 节假日标记
- 工作日/周末

**防泄漏**：
- 温度用"预测时点的天气预报" ✓
- 不能用"实际温度" ✗（预测时拿不到）

### 5. 模型选择

- ARIMA：单变量，无法加温度 → 淘汰
- Prophet：可加节假日，但单序列 → 备选
- LightGBM + 时序特征 + 温度 → 选用

### 6. 节假日处理

**问题**：春节负荷骤降，模型预测偏高

**方案**：
- 加入"春节标记"特征
- 春节前后 7 天单独标记
- 用历史春节模式调整

### 7. 评估

**时序 split**：训练用前 10 个月，测试用后 2 个月

| 指标 | 值 | 判定 |
|------|----|------|
| MAPE | 3.8% | 达标 |
| 春节 MAPE | 6.5% | 偏高 |
| 极端天气 MAPE | 8.2% | 偏高 |

**问题**：春节和极端天气预测偏弱
**修正**：加入更多春节历史样本、极端天气标记

### 8. 教训
- 时序数据有多季节，要全部识别
- 温度用天气预报而非实际值（防泄漏）
- 节假日单独处理，不能当普通日
- 时序 split 不能随机
- 极端场景要单独评估

## 三、思考练习

1. 选你的一个时序数据，做 STL 分解，识别趋势和季节。
2. 构造 5 个时序特征，检查有无泄漏。
3. 设计时序 split 方案，说明为什么不能随机。

---

## 四、今日小结

- 时序分解：趋势 + 季节 + 残差
- 平稳性是 ARIMA 前提，差分转换
- 树模型 + 时序特征常优于纯时序模型
- 特征只能用预测时点之前的数据
- 评估用时序 split + 回测，不能随机
- 节假日和极端场景单独处理
