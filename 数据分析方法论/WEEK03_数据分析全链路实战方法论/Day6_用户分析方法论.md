# Day6 · 用户分析方法论

> 用户是业务的根本。用户分析是把"流量"变成"人"来理解。

---

## 一、方法论框架

### 1. Cohort 分析（同期群分析）

**定义**：按某个共同特征（通常注册时间）分组，跟踪各组后续行为。

**典型应用**：留存分析
```
           第1周  第2周  第3周  第4周
1月注册组   100%   60%   45%   38%
2月注册组   100%   55%   40%   33%
3月注册组   100%   50%   38%   30%
```

**价值**：
- 看不同时期获客质量
- 看产品改进对留存的影响
- 比整体留存更精细

**分组维度**：注册时间 / 获客渠道 / 首次行为

### 2. RFM 模型

| 维度 | 含义 | 高 | 低 |
|------|------|----|----|
| Recency | 最近消费距今 | 近 | 远 |
| Frequency | 消费频次 | 高 | 低 |
| Monetary | 消费金额 | 高 | 低 |

**8 类用户**（见 WEEK01 Day4）

**进阶**：RFM + 行为标签
- R 高 F 高 M 高 + "夜间活跃" → VIP 夜猫用户
- R 低 F 高 M 高 → 流失大客户，重点召回

### 3. 用户路径分析

**漏斗分析**：
```
曝光 10000
  ↓ 点击 3000（30%）
    ↓ 加购 1000（33%）
      ↓ 下单 600（60%）
        ↓ 支付 540（90%）
```

**路径分析**：
- 用户实际走的路径（非预设漏斗）
- 发现意外路径、流失节点
- 常用：Sankey 图、状态转移矩阵

**流失节点定位**：
- 哪一步流失最多？
- 流失用户和未流失用户有什么不同？

### 4. 用户生命周期价值（LTV）

**定义**：一个用户在整个生命周期带来的总价值。

**计算**：
```
LTV = ARPU × 生命周期长度
    = ARPU × (1 / 流失率)
```

**用途**：
- 决定获客成本上限（CAC < LTV/3 才健康）
- 用户分层：高 LTV 用户重点维护
- 渠道评估：高 LTV 渠道加投

**预测 LTV**：
- 历史法：用历史数据算
- 预测法：用模型预测未来价值（BG/NBD + Gamma-Gamma）

### 5. 用户分层方法论

| 方法 | 适用 | 维度 |
|------|------|------|
| RFM | 交易用户 | R/F/M |
| 行为分层 | 内容用户 | 频率/深度/时长 |
| 价值分层 | 全用户 | LTV |
| 生命周期 | 全用户 | 新/活/沉睡/流失 |
| 聚类 | 探索性 | 多维自动 |

**分层原则**：
- 可解释（每类能用业务语言描述）
- 可行动（每类有对应策略）
- 稳定（用户不会频繁跳层）

### 6. 用户分群策略设计

```
分层 → 画像 → 策略 → 触达 → 效果 → 迭代
```

**每个分层要回答**：
- 这类用户是谁？（画像）
- 他们要什么？（需求）
- 我们做什么？（策略）
- 预期效果？（指标）
- 怎么衡量？（A/B）

## 二、案例复盘：某电商用户分层运营

### 1. 业务背景
- 月活 500 万，但增长停滞
- 现状：全量推送同一活动，效果差
- 目标：分层运营提升 ROI

### 2. RFM 分层

| 群体 | R | F | M | 占比 | 策略 |
|------|---|---|---|------|------|
| 重要价值 | 高 | 高 | 高 | 8% | VIP 维护 |
| 重要保持 | 高 | 高 | 低 | 5% | 提客单 |
| 重要发展 | 高 | 低 | 高 | 3% | 提频次 |
| 新用户 | 高 | 低 | 低 | 15% | 转化引导 |
| 重要挽留 | 低 | 高 | 高 | 4% | 召回 |
| 一般维持 | 低 | 高 | 低 | 10% | 促活 |
| 流失 | 低 | 低 | 低 | 55% | 低成本触达 |

### 3. Cohort 分析

**按注册月分组看留存**：
```
           次日   7日   30日
1月注册     60%   40%   25%
2月注册     55%   35%   20%
3月注册     50%   30%   18%
```

**发现**：新用户留存逐月下降
**原因**：3 月新版引导流程上线
**行动**：A/B 测试新旧引导

### 4. 路径分析

**新用户路径**：
```
注册 → 浏览首页 → 看商品 → 离开（60%）
注册 → 浏览首页 → 搜索 → 看商品 → 加购（25%）
注册 → 浏览首页 → 看推荐 → 加购（15%）
```

**发现**：60% 新用户看完商品就走了，没加购
**行动**：商品页加"新人专享"引导

### 5. LTV 计算

**按渠道 LTV**：
| 渠道 | CAC | LTV | LTV/CAC |
|------|-----|-----|---------|
| 渠道 A | 50 | 200 | 4 |
| 渠道 B | 80 | 150 | 1.9 |
| 渠道 C | 30 | 100 | 3.3 |

**行动**：渠道 B LTV/CAC < 3，减少投放

### 6. 分层运营效果

| 群体 | 策略 | 效果 |
|------|------|------|
| 重要价值 | VIP 专属客服 | 复购 +15% |
| 新用户 | 新人专享引导 | 转化 +20% |
| 重要挽留 | 个性化召回 | 召回率 +8% |
| 流失 | 低成本短信 | 召回率 +2% |

### 7. 教训
- 全量同策略效果差，分层后 ROI 提升
- Cohort 暴露新用户留存问题
- 路径分析定位流失节点
- LTV 指导渠道预算分配
- 分层要可解释、可行动

## 三、思考练习

1. 用 RFM 把你的用户分 8 类，选一类设计运营策略。
2. 做一个 Cohort 分析，看不同时期获客的留存差异。
3. 计算你的核心用户 LTV，判断获客成本是否健康。
