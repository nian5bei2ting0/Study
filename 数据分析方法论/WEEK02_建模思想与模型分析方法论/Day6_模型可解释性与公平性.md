# Day6 · 模型可解释性与公平性

> 黑盒模型不是不能解释，是要主动去解释。不解释，业务不信任，监管不通过。

---

## 一、方法论框架

### 1. 为什么需要可解释性

| 场景 | 需求 |
|------|------|
| 合规监管 | 信贷需说明拒贷理由 |
| 业务信任 | 运营要知道为什么这么推 |
| 模型调试 | 出错要知道哪个特征导致 |
| 伦理公平 | 不能因某特征歧视群体 |

### 2. 全局解释 vs 局部解释

| 类型 | 回答 | 方法 |
|------|------|------|
| 全局 | 整体上哪些特征重要 | 特征重要性、部分依赖图 |
| 局部 | 这个预测为什么是这个结果 | SHAP、LIME、反事实 |

### 3. 主流解释方法

**特征重要性**：
- 树模型：基尼不纯度减少量
- 线性模型：标准化系数
- 缺点：不知道正负方向，不交互

**部分依赖图（PDP）**：
- 一个特征变化时，预测如何变
- 缺点：忽略特征交互

**SHAP（SHapley Additive exPlanations）**：
- 基于博弈论的 Shapley 值
- 每个特征对单个预测的贡献
- 可正可负，可加和等于预测值 - 基线
- 优点：理论上严谨、可局部可全局

**LIME**：
- 在预测点附近用简单模型近似
- 优点：模型无关
- 缺点：近似而非精确

**反事实解释**：
- "如果收入 +1 万，就会批准"
- 优点：可行动、易理解

### 4. 公平性

**为什么关注公平**：
- 伦理：不应因种族、性别歧视
- 合规：监管要求
- 业务：歧视会损失用户

**公平性定义**：
| 定义 | 含义 |
|------|------|
| 机会均等 | 各群体真正例率相同 |
| 人群均等 | 各群体预测正例率相同 |
| 校准 | 各群体预测概率=实际概率 |

**注意**：不同公平定义可能冲突，不能同时满足。

### 5. 偏差来源

| 来源 | 说明 | 对策 |
|------|------|------|
| 数据偏差 | 训练数据不代表群体 | 重采样、加权 |
| 标签偏差 | 历史标签有偏见 | 审查标注过程 |
| 特征偏差 | 某特征是歧视代理 | 移除或调整 |
| 算法偏差 | 算法放大了偏差 | 公平性约束 |
| 部署偏差 | 上线后反馈循环 | 监控群体差异 |

### 6. 公平性审计流程

```
1. 定义敏感群体（性别/种族/地域/年龄）
2. 选公平性指标（机会均等/人群均等）
3. 分群体计算模型表现
4. 对比差异，超阈值则告警
5. 根因分析：数据/特征/标签
6. 修正：重采样/去偏/约束
7. 重新审计
```

## 二、案例复盘：某信贷模型公平性审计

### 1. 业务背景
- 信贷审批模型，整体准确率 88%
- 上线后被投诉：某地区通过率显著偏低
- 监管要求审计

### 2. 分群体表现

| 地区 | 样本量 | 通过率 | 真正例率 | 假正例率 | AUC |
|------|--------|--------|---------|---------|-----|
| A 区 | 5000 | 65% | 72% | 18% | 0.85 |
| B 区 | 3000 | 65% | 70% | 17% | 0.84 |
| C 区 | 2000 | 42% | 68% | 12% | 0.79 |

**发现**：C 区通过率显著低于 A/B 区，且 AUC 也偏低

### 3. 根因分析

**数据偏差**：
- C 区历史样本少（2000 vs 5000）
- C 区正样本比例低（30% vs 50%）

**特征偏差**：
- "居住年限"特征：C 区流动人口多，年限短
- 但年限短 ≠ 信用差，是地区特征代理
- → "居住年限"成了地区歧视代理

**标签偏差**：
- 历史上 C 区被人工拒贷多，标签本身有偏

### 4. 修正方案

**数据层**：
- C 区过采样
- 调整 class_weight

**特征层**：
- 移除"居住年限"或按地区标准化
- 加入"地区"作为公平性约束特征

**算法层**：
- 用公平性约束（如 adversarial debiasing）
- 优化目标加入群体差异惩罚

### 5. 修正后效果

| 地区 | 通过率 | AUC | 群体差异 |
|------|--------|-----|---------|
| A 区 | 62% | 0.84 | - |
| B 区 | 63% | 0.83 | - |
| C 区 | 60% | 0.82 | 显著缩小 |

**代价**：整体 AUC 从 0.85 降到 0.83
**权衡**：公平性优先于整体精度

### 6. 教训
- 不审计公平性，模型会无意中歧视
- "居住年限"看似中性，实为地区代理
- 公平性要主动设计，不能靠模型自动实现
- 公平与精度有权衡，需业务决策

## 三、思考练习

1. 选你的一个模型，用 SHAP 解释 3 个预测。
2. 定义你的敏感群体，做一次公平性审计。
3. 找一个可能的"歧视代理特征"，分析为什么。

## 四、今日小结

- 可解释性是合规、信任、调试的基础
- SHAP 是当前最严谨的解释方法
- 公平性要主动审计，不能靠模型自动
- 偏差来源：数据、标签、特征、算法、部署
- 公平与精度有权衡，需业务决策
