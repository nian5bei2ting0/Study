# WEEK02 · 建模思想与模型分析方法论

> **本周目标**：理解建模的本质思想，掌握从特征到评估的完整建模方法论。
> **核心问题**：拿到一个建模需求，如何决定"建不建、建什么、怎么评、怎么上"？

---

## 本周路线

| Day | 主题 | 方法论核心 | 案例复盘 |
|-----|------|-----------|---------|
| 1 | 建模的本质与思想 | 模型是什么 / 假设 / 偏差-方差 / 奥卡姆剃刀 | 某场景"该不该建模"的决策 |
| 2 | 特征工程方法论 | 构造原则 / 选择方法 / 稳定性监控 | 某信贷反欺诈特征体系 |
| 3 | 算法选型决策框架 | 选型决策树 / 何时不用模型 | 某零售销量预测选型 |
| 4 | 模型评估方法论 | 离线/在线 / 业务指标对齐 | 某推荐系统评估体系 |
| 5 | 因果推断与 A/B 测试 | 相关≠因果 / ATE / 反事实 / 分流 | 某功能上线因果评估 |
| 6 | 模型可解释性与公平性 | SHAP / LIME / 群体偏差审计 | 某信贷模型公平性审计 |
| 7 | 综合复盘与模型交接文档 | 全链路文档 / 上线三道门 | 某 SaaS 流失预警全链路 |
