# Day5 · 因果推断与 A/B 测试

> 相关性不等于因果性。A/B 测试是验证因果的金标准。

---

## 一、方法论框架

### 1. 相关 ≠ 因果

**经典案例：辛普森悖论**
- 整体看：治疗 A 治愈率 78%，治疗 B 治愈率 83% → B 更好
- 分层看：轻症 A 93% vs B 87%，重症 A 70% vs B 63% → A 都更好
- 真相：B 接收了更多轻症病人，整体被拉高

**教训**：不看分层，可能得出相反结论。

**混淆变量**：C 同时影响 A 和 B，让 A 和 B 看起来相关，但 A 不导致 B。
- 例：冰淇淋销量和溺水率正相关，但不是因果——夏天（C）同时影响两者

### 2. A/B 测试

**定义**：随机分流，对比实验组（A）和对照组（B）的差异。

**核心要素**：
| 要素 | 说明 |
|------|------|
| 假设 | H0：无差异；H1：有差异 |
| 指标 | 主指标 + 护栏指标 |
| 分流 | 随机、均匀、可追溯 |
| 样本量 | 达到统计显著的最小样本 |
| 周期 | 至少一个完整业务周期 |
| 显著性 | p < 0.05（或更严） |

**样本量计算**：
- 基线转化率 p
- 最小可检测效应 MDE
- 显著性水平 α（通常 0.05）
- 检验功效 1-β（通常 0.8）
- 样本量 ≈ 16 × p(1-p) / MDE²

### 3. A/B 测试的陷阱

| 陷阱 | 说明 | 防范 |
|------|------|------|
| 网络效应 | 用户互相影响 | 按群体分流而非个体 |
| 辛普森悖论 | 分层结论相反 | 分层分析 |
| 提前停止 | 看到显著就停 | 预先定样本量 |
| 多重比较 | 多指标多测试 | Bonferroni 校正 |
| 新奇效应 | 新功能短期好 | 等足够长周期 |
| 污染 | 实验组对照组交叉 | 严格分流隔离 |

### 4. 因果推断入门

**何时不能做 A/B 测试**：
- 伦理限制（如医疗）
- 无法随机分流（如定价）
- 样本量不足
- 网络效应太强

**观察性研究的因果方法**：

| 方法 | 适用 | 核心 |
|------|------|------|
| 倾向得分匹配（PSM） | 可观测混淆 | 匹配相似个体 |
| 双重差分（DID） | 政策/事件 | 对比时间趋势差异 |
| 工具变量（IV） | 不可观测混淆 | 找外生变量 |
| 断点回归（RDD） | 阈值政策 | 阈值附近对比 |

### 5. 因果效应指标

| 指标 | 含义 |
|------|------|
| ATE | 平均处理效应（全人群） |
| ATT | 处理组平均效应（实际接受处理的人） |
| CATE | 条件平均效应（某子群体） |
| 反事实 | 如果没接受处理会怎样 |

### 6. A/B 测试方案模板

```
1. 实验目的：验证什么假设
2. 主指标：______
3. 护栏指标：______（不能变差的）
4. 分流方案：______（按什么分流）
5. 样本量：______（计算依据）
6. 实验周期：______（含完整周期）
7. 显著性标准：______
8. 决策规则：显著且正向 → 全量；显著负向 → 回滚；不显著 → 判断是否继续
9. 风险预案：护栏指标恶化时回滚
```

## 二、案例复盘：某功能上线因果评估

### 1. 业务背景
- 某社交 App 上线"推荐好友"功能
- 上线后次日留存 +3%
- 业务方问：是功能带来的，还是自然波动？

### 2. 第一版方案（错误）

**做法**：对比上线前后留存
- 上线前：次日留存 40%
- 上线后：次日留存 43%
- 结论：功能提升留存 3%

**问题**：
- 没有对照组
- 可能是季节性、活动、市场变化导致
- 不能归因到功能

### 3. 第二版方案（A/B 测试）

**方案**：
- 分流：按 user_id hash，50% 实验组（有功能），50% 对照组（无功能）
- 主指标：次日留存
- 护栏指标：使用时长、负反馈率
- 周期：2 周（覆盖周末）
- 样本量：每组 10 万

**结果**：
| 指标 | 实验组 | 对照组 | 差异 | p 值 |
|------|--------|--------|------|------|
| 次日留存 | 43% | 41% | +2% | 0.03 |
| 使用时长 | 25min | 24min | +1min | 0.15 |
| 负反馈率 | 0.8% | 0.7% | +0.1% | 0.04 |

**结论**：
- 留存显著提升 +2%（不是 +3%，原对比有水分）
- 使用时长无显著差异
- 负反馈率显著上升（护栏指标恶化）

**决策**：暂缓全量，先优化负反馈问题

### 4. 网络效应干扰

**发现**：实验组用户会推荐给对照组用户，导致对照组也受影响
- → 对照组留存也被拉高，稀释了实验效应
- 真实效应可能 > 2%

**修正**：按社交圈分流而非个体
- 把整个好友圈分到同一组
- 重新实验，效应 +3.5%

### 5. 教训
- 上线前后对比不是因果评估
- A/B 测试要设护栏指标
- 网络效应会稀释效应，需按群体分流
- 护栏指标恶化要暂缓，不能只看主指标

## 四、今日小结

- 相关 ≠ 因果，辛普森悖论会反转结论
- A/B 测试是因果验证金标准
- 样本量、周期、护栏指标要预先定
- 网络效应需按群体分流
- 不能 A/B 时用 PSM/DID/IV/RDD
