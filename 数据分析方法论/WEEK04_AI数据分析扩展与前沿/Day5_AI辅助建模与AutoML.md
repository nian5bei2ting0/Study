# Day5 · AI 辅助建模与 AutoML

> AutoML 让建模门槛降低，但"选对问题"仍是人的核心价值。

---

## 一、方法论框架

### 1. AutoML 的能力

| 能力 | 说明 |
|------|------|
| 特征自动生成 | Featuretools 等 |
| 模型自动选择 | 试多个算法选最优 |
| 超参自动调优 | 贝叶斯优化 |
| 自动集成 | Stacking/Blending |
| 自动评估 | 交叉验证 + 多指标 |

### 2. AutoML 工具

| 工具 | 特点 | 适用 |
|------|------|------|
| Auto-sklearn | sklearn 生态 | 表格数据 |
| TPOT | 自动 pipeline | 表格数据 |
| H2O AutoML | 企业级 | 大数据 |
| AutoGluon | 多模态 | 表格/图像/文本 |
| Featuretools | 特征工程 | 衍生特征 |

### 3. AI 辅助建模流程

```
1. 人定义问题 → AI 建议建模方案
2. AI 自动特征生成 → 人审核特征
3. AutoML 试多模型 → 人看结果
4. AI 自动调参 → 人评估
5. AI 生成模型报告 → 人决策上线
```

### 4. 特征自动生成

**Featuretools**：
- 深度特征合成（DFS）
- 自动从关系表生成衍生特征
- 例：从"交易表"自动生成"用户近 30 天交易次数"

**风险**：
- 生成大量特征，可能过拟合
- 部分特征不可解释
- 可能有时序泄漏

**防范**：
- 限制特征数量
- 人工筛选可解释特征
- 严格时序验证

### 5. AutoML 的边界

| 适用 | 不适用 |
|------|--------|
| 表格数据 | 需要深度业务理解 |
| 标准问题 | 定制化建模 |
| 快速 baseline | 极致精度需求 |
| 资源充足 | 资源受限 |

**何时回退人工**：
- AutoML 效果不达标
- 需要强可解释性
- 业务有特殊约束
- 数据需要深度处理

### 6. AI 辅助建模的完整方案

| 环节 | AI 辅助 | 人主导 |
|------|---------|--------|
| 问题定义 | 建议方案 | 确认问题 |
| 特征工程 | 自动生成 | 筛选 + 业务特征 |
| 模型选择 | AutoML | 看结果 + 业务判断 |
| 调参 | 自动调优 | 设定搜索空间 |
| 评估 | 自动多指标 | 业务指标对齐 |
| 上线 | 生成部署代码 | 决策 + 监控设计 |

## 二、案例复盘：某 AutoML vs 人工建模对比

### 1. 任务
- 信贷违约预测，二分类
- 数据：5 万样本，30 特征
- 目标：AUC > 0.8

### 2. 人工建模

| 环节 | 时间 | 动作 |
|------|------|------|
| EDA | 2 小时 | 理解数据 |
| 特征工程 | 4 小时 | 业务特征 + 衍生 |
| 模型试验 | 3 小时 | LR / RF / GBDT |
| 调参 | 2 小时 | GridSearch |
| 评估 | 1 小时 | 多指标 + 公平性 |
| **总计** | **12 小时** | - |

**结果**：AUC 0.83，可解释性强

### 3. AutoML 建模

| 环节 | 时间 | 动作 |
|------|------|------|
| 数据准备 | 30 分钟 | 格式化 |
| AutoML 运行 | 2 小时 | 自动跑（含特征+模型+调参） |
| 结果审核 | 1 小时 | 看报告 + 特征 |
| **总计** | **3.5 小时** | - |

**结果**：AUC 0.84，但特征不可解释

### 4. 对比

| 维度 | 人工 | AutoML |
|------|------|--------|
| 时间 | 12 小时 | 3.5 小时 |
| AUC | 0.83 | 0.84 |
| 可解释性 | 高 | 低 |
| 特征数 | 15（精选） | 80（自动） |
| 业务特征 | 有 | 无 |
| 部署难度 | 低 | 中 |

### 5. 决策

**选择**：人工建模
**理由**：
- 信贷场景需要可解释性（合规）
- AutoML 多 0.01 AUC 不值得牺牲可解释性
- 人工特征含业务知识，更稳定

### 6. 何时选 AutoML

- 快速 baseline：先跑 AutoML 看上限
- 不需要解释：推荐/排序场景
- 时间紧：原型阶段
- 非关键决策：辅助参考

### 7. 教训
- AutoML 快但不一定优
- 可解释性场景人工更合适
- AutoML 特征多但可能不可解释
- 用 AutoML 做 baseline，人工做精修

## 三、思考练习

1. 用 AutoML 跑一个你的数据集，对比人工建模的效果和效率。
2. 评估你的场景是否适合 AutoML（可解释性/时间/精度需求）。
3. 设计"AutoML baseline + 人工精修"的混合方案。

---

## 四、今日小结

- AutoML 能：自动特征、模型、调参、集成
- AutoML 不能：业务理解、可解释性保障
- 适合：快速 baseline、非关键决策
- 不适合：需可解释性、深度业务理解
- 最佳实践：AutoML baseline + 人工精修
