# WEEK04 · AI 数据分析扩展与前沿

> **本周目标**：理解 AI 如何变革数据分析范式，掌握用 LLM 作为分析副驾的方法论。
> **核心问题**：AI 时代，分析师的角色、方法、工具如何升级？

---

## 本周路线

| Day | 主题 | 方法论核心 | 案例复盘 |
|-----|------|-----------|---------|
| 1 | AI 数据分析范式变革 | 传统 vs AI 范式 / 能力边界 / 新角色 | 某团队引入 AI 后的工作流变化 |
| 2 | LLM 作为数据分析副驾 | 对话式分析 / 代码生成 / 解释辅助 | 用 LLM 完成 EDA 全流程 |
| 3 | Prompt 工程在数据分析中的应用 | 分析专用 Prompt / 结构化输出 / 链式推理 | 用 Prompt 生成分析报告框架 |
| 4 | AI 辅助 EDA 与数据清洗 | 自动洞察 / 异常检测 / 数据画像 | 某数据集 AI 辅助 EDA 对比 |
| 5 | AI 辅助建模与 AutoML | 特征自动生成 / 模型选择 / 调参 | 某 AutoML vs 人工建模对比 |
| 6 | AI 数据产品与智能分析 Agent | 自然语言取数 / 智能归因 / Agent 架构 | 某公司智能分析 Agent 设计 |
| 7 | 综合复盘与未来趋势 | 多模态 / Agentic AI / 人机协作 | 数据分析师未来能力模型 |
