# 数据建模分析及方法论 · 5 周学习计划

> **定位**：系统化的数据分析学习包，从统计基础到方法论到 AI 扩展。
> **主线**：统计基础 → 分析思维 → 建模思想 → 全链路实战 → AI 扩展。
> **周期**：5 周 × 7 天 = 35 天，每天 1.5-2 小时。
> **每日结构**：原理/框架（40%）+ 完整案例复盘（40%）+ 思考练习（20%）。
> **唯一原则**：**每个方法都能回答"为什么这么做"和"不这么做会怎样"。**

## 为什么从统计基础开始

方法论教"**怎么想**"，统计基础教"**怎么算、为什么这么算**"。
没有统计基础，方法论是空中楼阁：
- 学了"A/B 测试要算样本量"，但不知道公式从哪来
- 学了"相关 ≠ 因果"，但不知道怎么算相关
- 学了"用 p 值判断显著性"，但不知道 p 值到底是什么

WEEK00 补齐地基，让后续方法论每个框架都能理解"为什么这么设计"。

## 学完 5 周你能做到

### 统计基础（WEEK00）
- [ ] 理解概率与常见分布，知道什么数据服从什么分布
- [ ] 用统计量描述数据分布形态，理解均值/中位数的适用边界
- [ ] 解释中心极限定理，理解为什么样本能推断总体
- [ ] 做假设检验，正确解读 p 值和置信区间
- [ ] 计算并解读相关性，区分 Pearson/Spearman
- [ ] 做简单线性/逻辑回归，解读系数和 R²

### 分析思维（WEEK01）
- [ ] 用 MECE + 假设树拆解模糊业务问题
- [ ] 为业务场景设计三层指标体系
- [ ] 用杜邦分解 / RFM / 5W2H 等框架结构化分析

### 建模思想（WEEK02）
- [ ] 判断"该不该建模"并说明理由
- [ ] 用选型决策表为真实场景选模型
- [ ] 设计离线 + 在线评估体系
- [ ] 设计 A/B 测试并识别因果陷阱

### 全链路实战（WEEK03）
- [ ] 区分描述 / 诊断 / 预测 / 规范四类分析
- [ ] 针对不同目标选择正确分析路径
- [ ] 完成端到端分析并产出可执行建议

### AI 扩展（WEEK04）
- [ ] 用 LLM 作为分析副驾完成 EDA
- [ ] 编写分析专用 Prompt 模板
- [ ] 评估 AI 数据产品的适用边界
- [ ] 描绘个人未来能力地图

## 使用建议

1. **按周推进**：每周一个主题，7 天递进，不要跳周。
2. **WEEK00 是地基**：零基础务必先学，有基础可快速过。
3. **先读后练**：每天先读原理/方法论，再复盘案例，最后做练习。
4. **动手敲代码**：WEEK00 配套代码必须跑一遍，看真实输出。
5. **结合实际**：把案例复盘的方法套用到你自己的业务场景。
6. **模板复用**：`templates/` 下的模板可直接用于真实工作。
7. **回顾复盘**：每周末做一次本周回顾，画出自己的"方法论地图"。
